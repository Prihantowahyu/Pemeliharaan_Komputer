Konfigurasi DNS Server BIND9 (Forward & Reverse Lookup Zone)

Membangun Domain Name System (DNS) internal enterprise menggunakan BIND9, konfigurasi file zona pemetaan nama ke IP (Forward) dan IP ke nama (Reverse PTR), serta pengujian query record menggunakan dig dan nslookup.

1 Anatomi Tipe DNS Resource Record

Tipe RecordFungsi UtamaContoh Format Baris Record
SOA (Start of Authority)Informasi otoritas zona utama & serial serial number zone transfer@ IN SOA ns.smk.lan. admin.smk.lan. (...)
NS (Name Server)Menentukan server nama yang bertanggung jawab atas domain@ IN NS ns.smk.lan.
A (Address IPv4)Memetakan nama domain/subdomain ke alamat IPv4server IN A 192.168.10.1
CNAME (Canonical Name)Nama alias yang merujuk ke domain utamawww IN CNAME smk.lan.
PTR (Pointer)Reverse DNS: Memetakan oktet IP ke nama domain1 IN PTR smk.lan.
MX (Mail Exchange)Mengarahkan email domain ke Mail Server prioritas@ IN MX 10 mail.smk.lan.

2 Langkah Konfigurasi BIND9 Server

# 1. Deklarasi Zona pada /etc/bind/named.conf.local
zone "smk.lan" {
    type master;
    file "/etc/bind/db.smk.lan";
};

zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};
# 2. File Forward Zone: /etc/bind/db.smk.lan
$TTL    604800
@       IN      SOA     ns.smk.lan. admin.smk.lan. (
                              2026083101         ; Serial
                                  604800         ; Refresh
                                   86400         ; Retry
                                 2419200         ; Expire
                                  604800 )       ; Negative Cache TTL
;
@       IN      NS      ns.smk.lan.
@       IN      A       192.168.10.1
ns      IN      A       192.168.10.1
www     IN      CNAME   smk.lan.
mail    IN      A       192.168.10.1
@       IN      MX  10  mail.smk.lan.
# 3. File Reverse Zone: /etc/bind/db.192
$TTL    604800
@       IN      SOA     ns.smk.lan. admin.smk.lan. (
                              2026083101 604800 86400 2419200 604800 )
@       IN      NS      ns.smk.lan.
1       IN      PTR     smk.lan.
