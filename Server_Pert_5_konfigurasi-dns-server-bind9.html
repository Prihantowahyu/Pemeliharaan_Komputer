Konfigurasi DNS Server BIND9 (Forward & Reverse Zone)

Mengonversi alamat domain ramah manusia (seperti sekolah.sch.id) menjadi alamat IP server (dan sebaliknya) menggunakan BIND9 di Linux Server.

1 Tipe-Tipe DNS Record Utama

DNS (Domain Name System) menggunakan file zona yang memetakan nama ke resource record:

A Record (Address)
Memetakan nama domain ke IPv4 (contoh: tkj.sch.id -> 192.168.10.1).
CNAME (Canonical Name)
Nama alias untuk domain utama (contoh: www -> tkj.sch.id).
PTR Record (Pointer)
Reverse DNS: memetakan alamat IP kembali ke nama domain.
MX Record (Mail Exchange)
Mengarahkan lalu lintas email domain ke Mail Server tujuan.

2 Konfigurasi Forward & Reverse Zone (BIND9)

# 1. Instalasi paket BIND9 & DNS Utils
sudo apt install -y bind9 bind9utils dnsutils

# 2. Deklarasi Zona di /etc/bind/named.conf.local
zone "smk.lan" {
    type master;
    file "/etc/bind/db.smk.lan";
};

zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};
# Isi file Forward Zone: /etc/bind/db.smk.lan
$TTL    604800
@       IN      SOA     ns.smk.lan. admin.smk.lan. ( 2026083101 604800 86400 2419200 604800 )
@       IN      NS      ns.smk.lan.
ns      IN      A       192.168.10.1
@       IN      A       192.168.10.1
www     IN      CNAME   smk.lan.
mail    IN      A       192.168.10.1

3 Verifikasi & Pengujian Resolusi Nama

# 1. Periksa validitas sintaks file zona
sudo named-checkconf
sudo named-checkzone smk.lan /etc/bind/db.smk.lan

# 2. Uji resolusi domain dari client
nslookup smk.lan 192.168.10.1
dig www.smk.lan @192.168.10.1
