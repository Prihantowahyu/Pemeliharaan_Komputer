1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Analogi Buku Telepon Internet 08.00 - 08.30 (30 Menit)

Apersepsi: Mengapa manusia lebih mudah mengingat nama google.com daripada alamat IP 142.250.190.46? Guru menjelaskan hierarki DNS global dari Root Server (.) → Top-Level Domain (.id, .com, .sch.id) → Second-Level Domain (smk.sch.id) → Host Record.

Fase 2: Arsitektur BIND9 & Jenis-Jenis DNS Resource Record 08.30 - 09.30 (60 Menit)

Pembedahan struktur direktori /etc/bind/ (named.conf.options, named.conf.local). Eksplorasi makna record: SOA (Start of Authority + Serial Number format YYYYMMDDNN), NS (Name Server), A (IPv4 Address), CNAME (Alias), MX (Mail Exchange), dan PTR (Pointer IP ke Domain).

Fase 3: Bedah Konfigurasi Forward & Reverse Zone File 09.30 - 10.30 (60 Menit)

Aturan krusial tanda TITIK di akhir nama domain FQDN (misal: ns.smk.lan.). Jika titik tertinggal, BIND9 otomatis menambahkan nama domain zona di belakangnya sehingga menjadi ns.smk.lan.smk.lan. (kesalahan paling fatal di dunia industri).

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Penyegaran dan persiapan eksekusi lab DNS master.

Fase 4: Job Sheet Praktikum Mandiri — Membangun Master DNS Sekolah 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet 5: (1) Install paket bind9 bind9utils dnsutils, (2) Deklarasikan zona forward smk.lan dan zona reverse 10.168.192.in-addr.arpa di named.conf.local, (3) Buat file zona db.smk.lan dan db.192, (4) Validasi dengan named-checkconf dan named-checkzone, (5) Uji query DNS lokal dan internet forwarders.

Fase 5: Skenario Kasus Gangguan & Investigasi 'dig' / 'nslookup' 13.15 - 14.15 (60 Menit)

Siswa mendiagnosis 3 kesalahan: Service BIND9 failed akibat titik koma (;) hilang, query menghasilkan status SERVFAIL, dan PTR record tidak merespons (Reverse lookup gagal).

Fase 6: Evaluasi CBT & Refleksi Akhir Blok 1 14.15 - 15.00 (45 Menit)

2 Konfigurasi Lengkap BIND9 Master DNS

# 1. /etc/bind/named.conf.local — Deklarasi Zona 
zone "smk.lan" {
    type master;
    file "/etc/bind/db.smk.lan";
};

zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};
# 2. /etc/bind/db.smk.lan — Forward Lookup Zone 
$TTL    86400
@       IN      SOA     ns.smk.lan. admin.smk.lan. (
                              2026083101 ; Serial (Format: YYYYMMDDNN)
                                  604800 ; Refresh (1 Minggu)
                                   86400 ; Retry (1 Hari)
                                 2419200 ; Expire (4 Minggu)
                                   86400 ) ; Negative Cache TTL

; Name Server Record
@       IN      NS      ns.smk.lan.

; Address Records (A)
ns      IN      A       192.168.10.10
portal  IN      A       192.168.10.10
mail    IN      A       192.168.10.10

; Canonical Name (Alias)
www     IN      CNAME   portal.smk.lan.
ftp     IN      CNAME   portal.smk.lan.

; Mail Exchanger Record
@       IN      MX  10  mail.smk.lan.
# 3. /etc/bind/db.192 — Reverse Lookup Zone (PTR Record) 
$TTL    86400
@       IN      SOA     ns.smk.lan. admin.smk.lan. (
                              2026083101 ; Serial
                                  604800 ; Refresh
                                   86400 ; Retry
                                 2419200 ; Expire
                                   86400 ) ; Negative Cache TTL

@       IN      NS      ns.smk.lan.

; Pointer Record: 10 adalah oktet terakhir dari IP 192.168.10.10
10      IN      PTR     portal.smk.lan.
10      IN      PTR     ns.smk.lan.

4 Laboratorium Troubleshooting: Serial Number & FQDN Trailing Dot

# ATURAN EMAS TROUBLESHOOTING DNS: 1. Selalu tambahkan tanda TITIK (.) di akhir FQDN (contoh: ns.smk.lan.) di file zona. 2. Setiap kali mengubah record IP, WAJIB menaikkan angka Serial Number di blok SOA (misal: 2026083101 → 2026083102) agar DNS cache dan slave server memperbarui datanya. 3. Restart daemon dan pantau log sistem secara real-time: sudo systemctl restart named && sudo journalctl -u named -e
