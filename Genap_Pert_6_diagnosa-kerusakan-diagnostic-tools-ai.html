Bagian A · HWiNFO64

A. Panduan Lengkap HWiNFO64: Membaca Telemetri Hardware

HWiNFO64 adalah software monitoring profesional gratis yang membaca lebih dari 500 parameter sensor dari CPU, GPU, motherboard, PSU, dan storage secara real-time.

Parameter CPU yang Wajib Dipantau

  • CPU Package Power: Konsumsi daya total prosesor (Watt). Jika konsisten di atas TDP nominal, sistem tidak mampu mendinginkan dengan baik.
  • CPU Package Temp: Suhu termal keseluruhan die CPU. Normal idle: 35-55°C. Batas aman saat load: 85°C. KRITIS: >95°C.
  • CPU Core VID: Tegangan yang dikirim ke core CPU. Nilai abnormal bisa indikasikan masalah BIOS atau OC instabil.
  • CPU Ratio (Multiplier): Clock multiplier aktif. Jika saat load turun drastis (misal 45x → 18x), CPU sedang throttling karena panas atau power limit.

Parameter GPU yang Wajib Dipantau

  • GPU Hotspot Temperature: Suhu titik terpanas di die GPU. Lebih representatif dari GPU Temperature biasa. Batas: <105°C.
  • GPU Memory Temperature: Suhu VRAM. Jika di atas 90°C, VRAM dalam bahaya. Solusi: re-pad thermal VRAM.
  • GPU Power (W): Konsumsi daya aktual GPU. Bandingkan dengan TGP resmi. Jika di bawah TGP, kemungkinan PSU tidak mampu mensuplai.
  • GPU Clock (MHz): Frekuensi core aktual. Jika sering drop saat gaming, indikasi thermal throttling atau power throttling GPU.
Bagian B · Stress Testing

B. Prosedur Stress Testing Hardware yang Terstandarisasi

Stress test memaksa hardware bekerja pada beban maksimal untuk menguji kestabilan sistem dalam kondisi ekstrem. Jika sistem crash, hang, atau artifak saat stress test, terdapat masalah yang perlu diperbaiki.

Prime95: CPU Stability Test

Prosedur: Pilih torture test type: Small FFTs (beban termal tertinggi untuk CPU, cocok untuk uji pendingin) atau Blend (kombinasi CPU + RAM). Jalankan selama 15-30 menit sambil memantau suhu di HWiNFO64.

Interpretasi: Worker error = ketidakstabilan CPU (tegangan OC terlalu rendah atau suhu terlalu tinggi). Sistem crash = masalah serius pada PSU atau RAM.

FurMark: GPU Stress Test

Prosedur: Pilih resolusi 1920x1080, aktifkan Fullscreen, klik GPU Burn-in Test. Jalankan 10-15 menit. Pantau GPU Hotspot Temperature dan GPU Memory Temperature di HWiNFO64.

Interpretasi: Artifak layar (titik-titik, warna acak) = masalah VRAM atau GPU overheating. Crash = GPU tidak stabil pada beban penuh atau PSU kekurangan daya.

MemTest86: RAM Integrity Test

Prosedur: Buat bootable USB menggunakan Rufus + MemTest86 ISO. Boot dari USB. Test berjalan otomatis menggunakan 13 algoritma pengujian berbeda pada seluruh kapasitas RAM tanpa keterlibatan OS Windows.

Interpretasi: Error count 0 = RAM sempurna. Error muncul = RAM bermasalah. Uji keping per keping untuk isolasi modul yang rusak.

Bagian C · Windows Logs

C. Membaca Log Windows Event Viewer & Reliability Monitor

Windows secara otomatis mencatat setiap event penting ke dalam log sistem. Log ini adalah "black box recorder" komputer yang sangat membantu diagnosis masalah intermittent.

Membuka Reliability Monitor (Grafis)

Tekan Win + R → ketik perfmon /rel. Reliability Monitor menampilkan grafik stabilitas sistem (Stability Index 0-10) secara historis. Titik merah menandai hari di mana terjadi crash atau error kritis. Klik titik merah untuk melihat detail insiden.

Filter Event ID Kritis di Event Viewer

Buka Event Viewer (eventvwr) → Windows Logs → System. Filter Log: Level = Critical & Error. Event ID penting: 41 (Kernel-Power: sistem restart tiba-tiba tanpa shutdown bersih — indikasi hardware atau driver crash), 6008 (shutdown tidak terduga sebelumnya), 1001 (BugCheck: BSOD dengan stop code).

Analisis Minidump dari BSOD

File crash dump disimpan di C:\Windows\Minidump\. Analisis menggunakan WinDbg atau online tool https://WinDbg.info. Minidump biasanya menyebutkan driver atau modul yang menyebabkan crash (contoh: nvlddmkm.sys = driver NVIDIA, ntfs.sys = masalah file sistem).

Soal 1: Apa yang dimaksud 'Distance to TjMax' dalam monitoring HWiNFO64 dan mengapa nilainya semakin kecil itu berbahaya?
A. Jarak fisik antara CPU dan heatsink dalam milimeter
B. Perbedaan antara suhu maksimum aman CPU (TjMax) dan suhu aktual saat ini — nilai kecil berarti CPU hampir mencapai batas termalnya dan akan throttling
C. Persentase performa CPU yang tersisa sebelum overclocking berhenti
D. Jarak antara CPU socket dan slot RAM dalam centimeter
Soal 2: Mengapa Prime95 dengan mode 'Small FFTs' menghasilkan suhu CPU lebih tinggi dibanding mode 'Blend'?
A. Karena Small FFTs menggunakan lebih banyak kapasitas RAM
B. Karena Small FFTs memaksimalkan aktivitas FPU (Floating Point Unit) dalam cache L1/L2 CPU tanpa banyak akses memori, menghasilkan panas paling tinggi per watt dengan cepat — ideal untuk menguji sistem pendingin
C. Karena Small FFTs lebih banyak menggunakan GPU dalam proses kalkulasinya
D. Karena Small FFTs menonaktifkan power saving feature CPU
Soal 3: Event ID 41 (Kernel-Power) di Windows Event Viewer mengindikasikan apa?
A. Update Windows berhasil diinstal
B. Sistem mengalami restart atau shutdown mendadak tanpa proses shutdown bersih — kemungkinan crash hardware (PSU, RAM, thermal), bukan software
C. Sistem baru pertama kali dinyalakan setelah pemasangan OS baru
D. Driver perangkat keras berhasil diperbarui secara otomatis
