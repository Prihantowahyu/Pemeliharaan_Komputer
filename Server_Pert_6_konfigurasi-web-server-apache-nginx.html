1 Konsep Name-Based Virtual Host

Name-based Virtual Host membaca HTTP header Host: smk.lan yang dikirim oleh browser client untuk mengarahkan request ke folder direktori yang tepat:

# 1. Buat folder web root untuk 2 domain berbeda
sudo mkdir -p /var/www/smk.lan/html
sudo mkdir -p /var/www/portal.smk.lan/html
sudo chown -R www-data:www-data /var/www/
sudo chmod -R 755 /var/www/

2 Konfigurasi Apache Virtual Host (/etc/apache2/sites-available/)

# File: /etc/apache2/sites-available/smk.lan.conf
<VirtualHost *:80>
    ServerAdmin admin@smk.lan
    ServerName smk.lan
    ServerAlias www.smk.lan
    DocumentRoot /var/www/smk.lan/html

    ErrorLog ${APACHE_LOG_DIR}/smk_error.log
    CustomLog ${APACHE_LOG_DIR}/smk_access.log combined

    <Directory /var/www/smk.lan/html>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
# Aktifkan konfigurasi Virtual Host & Modul Rewrite
sudo a2ensite smk.lan.conf
sudo a2enmod rewrite
sudo systemctl reload apache2
