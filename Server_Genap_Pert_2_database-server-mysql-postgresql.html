1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Prinsip ACID Transaksi Data 08.00 - 08.30 (30 Menit)

Apersepsi: Mengapa aplikasi perbankan atau sistem nilai siswa tidak boleh menggunakan file Excel biasa? Guru memaparkan 4 pilar ACID: Atomicity (semua query berhasil atau batal sama sekali), Consistency, Isolation (transaksi simultan tidak saling merusak), dan Durability (data tersimpan permanen pasca crash).

Fase 2: Instalasi & Hardening Keamanan MySQL/MariaDB 08.30 - 09.30 (60 Menit)

Pembedahan skrip mysql_secure_installation: Menghapus user anonymous, melarang remote login root, menghapus database 'test', dan memuat ulang tabel hak akses (FLUSH PRIVILEGES). Pembedahan file /etc/mysql/mariadb.conf.d/50-server.cnf.

Fase 3: Manajemen User Berbasis Host & Hak Akses Terisolasi 09.30 - 10.30 (60 Menit)

Membongkar sintaks keamanan SQL: CREATE USER 'app_user'@'192.168.10.%' IDENTIFIED BY 'PassKuat123!'; dan pemberian hak terbatas hanya pada database tertentu (GRANT SELECT, INSERT, UPDATE ON db_sekolah.* ...).

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Persiapan client GUI database (DBeaver / HeidiSQL) di laptop siswa.

Fase 4: Job Sheet Praktikum Mandiri — Remote Database & Dump Test 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet Genap 2: (1) Install MariaDB Server di Linux, (2) Buka port 3306 via bind-address = 0.0.0.0 & Firewall UFW, (3) Buat DB db_portal_siswa, (4) Sambungkan aplikasi DBeaver dari laptop client, (5) Buat tabel siswa dan input 10 baris data, (6) Eksekusi backup CLI mysqldump dan simulasikan restore.

Fase 5: Skenario Troubleshooting: Error 1045 & Error 2003 Connection Refused 13.15 - 14.15 (60 Menit)

Siswa mendiagnosis 2 kegagalan klasik: Error 2003 (MySQL hanya mendengarkan 127.0.0.1 loopback) dan Error 1045 (User terdaftar untuk host 'localhost' namun mencoba login dari remote IP).

Fase 6: Evaluasi CBT & Refleksi 9 JP 14.15 - 15.00 (45 Menit)

Pengerjaan evaluasi teori CBT 30 menit, checklist pengujian query remote oleh guru, dan pengantar materi Remote Access Server SSH & RDP.

2 Konfigurasi Remote & Perintah SQL User Grants

# 1. Edit /etc/mysql/mariadb.conf.d/50-server.cnf untuk mengaktifkan koneksi Remote # Ubah dari: bind-address = 127.0.0.1 bind-address = 0.0.0.0 sudo systemctl restart mariadb # 2. Perintah SQL Pembuatan Database & User Terisolasi CREATE DATABASE db_sekolah CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER 'dbadmin_web'@'192.168.10.%' IDENTIFIED BY 'PasswordSangatRahasia!2026'; GRANT ALL PRIVILEGES ON db_sekolah.* TO 'dbadmin_web'@'192.168.10.%'; FLUSH PRIVILEGES; # 3. Backup & Restore Database via CLI mysqldump -u root -p db_sekolah > /backup/db_sekolah_backup.sql mysql -u root -p db_sekolah < /backup/db_sekolah_backup.sql

4 Laboratorium Troubleshooting: Error 1045 Access Denied

# KASUS: ERROR 1045 (28000): Access denied for user 'dbadmin_web'@'192.168.10.25' # Penyebab: User di database dibuat dengan host 'localhost' ('dbadmin_web'@'localhost'), sehingga ditolak saat login dari laptop IP 192.168.10.25. # Solusi: Buat user dengan wildcard subnet '192.168.10.%' atau '%' (seluruh IP): GRANT ALL PRIVILEGES ON db_sekolah.* TO 'dbadmin_web'@'192.168.10.%' IDENTIFIED BY 'PassKuat123!'; FLUSH PRIVILEGES;
