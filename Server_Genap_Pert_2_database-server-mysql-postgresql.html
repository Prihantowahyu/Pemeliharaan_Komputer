Komparasi Mesin Database: MariaDB (Port 3306) vs PostgreSQL (Port 5432)
⏱ 08.30 – 09.30 · 60 Menit
▼
MySQL / MariaDB (Port 3306)
  • Paling populer untuk aplikasi Web CMS (WordPress, Moodle, Laravel)
  • Engine default: InnoDB (Mendukung Foreign Key & ACID Transaction)
  • Kecepatan query read sangat tinggi
PostgreSQL (Port 5432)
  • Object-Relational DBMS canggih dengan standar kepatuhan SQL tertinggi
  • Mendukung tipe data kompleks (JSONB, GIS Spasial, Array)
  • Sangat tangguh untuk transaksi perbankan & analitik Big Data
3
Konfigurasi Remote Access (/etc/mysql/mariadb.conf.d/50-server.cnf)
⏱ 09.30 – 10.30 · 60 Menit
▼

Secara default, MariaDB hanya mendengarkan koneksi lokal (127.0.0.1). Agar Web Server dari server lain dapat menghubungi database, ubah bind-address:

# /etc/mysql/mariadb.conf.d/50-server.cnf
bind-address = 0.0.0.0   # Izinkan mendengarkan dari seluruh IP interface

Praktikum Mandiri — Setup User Remote & mysqldump (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
1
Install MariaDB Server & Hardening:
sudo apt update && sudo apt install -y mariadb-server
sudo mysql_secure_installation
2
Buat Database dan User Remote khusus Web App:
sudo mariadb -u root
CREATE DATABASE db_sekolah;
CREATE USER 'user_web'@'192.168.10.%' IDENTIFIED BY 'PasswordRahasia123!';
GRANT ALL PRIVILEGES ON db_sekolah.* TO 'user_web'@'192.168.10.%';
FLUSH PRIVILEGES;
EXIT;
3
Backup Database otomatis via mysqldump:
mysqldump -u root -p db_sekolah > backup_sekolah_$(date +%F).sql
4
Uji Remote Connection dari Client Laptop:
mysql -u user_web -p -h 192.168.10.10 db_sekolah -e "SHOW TABLES;"
