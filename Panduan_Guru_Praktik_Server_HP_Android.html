  • Resource Sangat Ringan: 36 sesi SSH teks simultan hanya memakan RAM server sekitar ~180 MB!

2 Skrip Otomatisasi 1-Klik untuk Guru (Pembuat 36 Akun Siswa)

Guru cukup menyalin dan menjalankan satu blok skrip di bawah ini pada PC Server Guru. Skrip ini akan otomatis membuat 36 akun siswa (siswa01 s.d. siswa36) dengan password default tkj123 dan folder home yang terisolasi aman:

# Jalankan skrip ini sekali di terminal Server Guru:
sudo bash -c 'cat << "EOF" > /usr/local/bin/setup_lab_siswa.sh
#!/bin/bash
echo "=== MEMULAI SETUP 36 AKUN SISWA LAB TKJ ==="
groupadd -f siswa_lab

for i in $(seq -w 1 36); do
    USERNAME="siswa$i"
    PASSWORD="tkj$i"
    
    if id "$USERNAME" &>/dev/null; then
        echo "[-] User $USERNAME sudah ada."
    else
        useradd -m -s /bin/bash -g siswa_lab "$USERNAME"
        echo "$USERNAME:$PASSWORD" | chpasswd
        echo "[+] Berhasil membuat: $USERNAME (Password: $PASSWORD)"
    fi
done

echo "=== MEMASANG HAK AKSES PERMISSION ISOLASI ==="
chmod 711 /home/*
echo "=== SELESAI! 36 AKUN SIAP DIGUNAKAN SISWA ==="
EOF
chmod +x /usr/local/bin/setup_lab_siswa.sh
/usr/local/bin/setup_lab_siswa.sh'

3 Panduan Langkah demi Langkah untuk Siswa (Di Tampilkan di Proyektor)

1
Sambungkan HP ke WiFi Lab:

Buka pengaturan WiFi di HP → Hubungkan ke SSID LAB-TKJ-SERVER (Password: tkjbisa123).

2
Buka Aplikasi JuiceSSH di HP Android (atau Termux / Termius di iPhone):

Aplikasi gratis di Google Play Store (ukuran hanya ~12 MB).

3
Buat Koneksi SSH Baru:
ParameterNilai yang Diisi Siswa
NicknameServer Lab TKJ
TypeSSH
Address (Host)192.168.10.1
Port22
Identity (User)siswa01 (sesuai nomor absen masing-masing)
Passwordtkj01 (sesuai nomor absen)
4
Klik 'Connect' → Terminal Linux Aktif di Layar HP!

Siswa akan disambut dengan prompt bash: siswa01@server:~$ dan langsung bisa mengetik seluruh modul praktikum 1 s.d. 20!

4 Strategi Hybrid (Jika Ada Sebagian PC Lab Tersedia)

🖥️ Kelompok di PC Lab (Core Testing)
  • Bertindak sebagai Server Target & Load Stressor
  • Menjalankan browser client untuk menguji tampilan web
  • Memantau grafik utilisasi CPU via htop di monitor besar
📱 Kelompok di HP (Remote SysAdmin)
  • Bertindak sebagai Remote Administrator
  • Mengonfigurasi file Virtual Host, DNS BIND9, dan database via SSH
  • Mengerjakan CBT dan membaca modul PWA di browser HP
