// 01 — Landasan Belajar

Capaian & Tujuan Pembelajaran

CAPAIAN PEMBELAJARAN (CP)

Peserta didik mampu melakukan backup data, memulihkan sistem (restore), dan menyusun dokumentasi hasil perawatan komputer secara sistematis dan bertanggung jawab.

TUJUAN PEMBELAJARAN (TP)
  • 1Melakukan backup data ke media eksternal maupun layanan cloud.
  • 2Membuat dan menggunakan restore point / system image untuk memulihkan sistem.
  • 3Menyusun laporan/dokumentasi hasil perawatan selama satu blok pembelajaran.

// 03 — Isi Materi

Empat Kompetensi Hari Ini

SUB MATERI 01

Metode Backup Data

Backup = menyalin data penting ke tempat lain supaya tidak hilang saat komputer rusak, terkena virus, atau flashdisk hilang.

  • Eksternal: salin ke HDD/SSD eksternal atau flashdisk berkapasitas besar.
  • Cloud: unggah ke penyimpanan daring agar bisa diakses di mana saja.
  • Terjadwal: atur backup otomatis agar tidak lupa dilakukan manual.
💾 Google Drive ☁️ OneDrive 🗂️ HDD Eksternal 📀 NAS
SUB MATERI 02

Restore Point & System Image

Kalau backup menyelamatkan file, restore menyelamatkan seluruh kondisi sistem — seperti tombol "undo" raksasa untuk komputer.

  • Restore Point: catatan kondisi sistem (setting, driver, program) pada waktu tertentu.
  • System Image: salinan lengkap seluruh isi hard disk, termasuk sistem operasi.
  • Kapan dipakai: setelah instal aplikasi bermasalah, kena malware, atau update yang gagal.
🪟 Windows System Restore 🖼️ System Image Backup 🐧 Timeshift (Linux)
SUB MATERI 03

Penyusunan Laporan Perawatan

Teknisi profesional selalu meninggalkan jejak tertulis. Laporan membuktikan apa yang sudah dikerjakan dan menjadi acuan perawatan berikutnya.

  • Identitas unit (nomor aset, spesifikasi, lokasi).
  • Daftar kerusakan/temuan awal & tindakan yang dilakukan.
  • Hasil akhir, rekomendasi, dan tanda tangan teknisi.
📋 Template Laporan 🖊️ Berita Acara 📸 Dokumentasi Foto
SUB MATERI 04

Serah Terima Hasil Perawatan

Blok 2 ditutup dengan serah terima resmi: unit dikembalikan dalam kondisi baik disertai laporan lengkap sebagai bentuk tanggung jawab kerja.

  • Presentasikan hasil kerja & laporan ke guru/penanggung jawab unit.
  • Tunjukkan bukti backup & restore point yang berhasil dibuat.
  • Tanda tangani berita acara serah terima bersama.

// 08 — Standar Ketuntasan & Rubrik

Kriteria Ketuntasan (KKTP)

Kamu dinyatakan tuntas pada materi ini apabila:

  • Berhasil melakukan backup data ke media eksternal dan/atau cloud tanpa error.
  • Berhasil membuat restore point / system image yang terbukti bisa dipulihkan.
  • Menyusun laporan perawatan yang lengkap, rapi, dan sesuai template.

Rubrik penilaian unjuk kerja & laporan (skala 1–4):

AspekSkor 4Skor 3Skor 2Skor 1
Backup Data Backup berhasil ke 2 media berbeda, tanpa bantuan. Backup berhasil ke 1 media, tanpa bantuan. Backup berhasil dengan bantuan guru/teman. Belum berhasil melakukan backup.
Restore Point / Image Restore point dibuat & terbukti bisa memulihkan sistem, tanpa bantuan. Restore point dibuat dan berhasil, dengan sedikit arahan. Restore point dibuat namun butuh banyak bantuan. Belum berhasil membuat/menguji restore point.
Laporan Perawatan Lengkap, rapi, sistematis, sesuai template, mandiri. Lengkap sesuai template, sedikit kurang rapi. Sebagian komponen laporan belum lengkap. Laporan tidak sesuai template / tidak selesai.
Sikap & Kolaborasi Aktif berdiskusi, membantu teman, tanggung jawab tinggi. Aktif berdiskusi dan bertanggung jawab pada tugasnya. Perlu diingatkan untuk aktif/bertanggung jawab. Pasif dan kurang bertanggung jawab pada tugas.
