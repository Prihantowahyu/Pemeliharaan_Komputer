Manajemen User, Group & Hak Akses (Permission) di Linux Server

Mengelola otentikasi user & group, kontrol hak akses file/direktori dengan skema oktal (chmod/chown), hak administratif sudo, dan penerapan prinsip Least Privilege.

1 Perintah Manajemen User & Group

Di sistem Linux multi-user, setiap layanan dan pengguna harus memiliki identitas terpisah demi keamanan sistem:

# 1. Membuat group baru untuk tim web admin
sudo groupadd webdev

# 2. Membuat user baru dengan direktori home & shell bash
sudo useradd -m -s /bin/bash -g webdev ahmad
sudo passwd ahmad

# 3. Menambahkan user ke group sudo (hak admin)
sudo usermod -aG sudo ahmad

2 Hak Akses File & Direktori (rwx & Nilai Oktal)

Setiap file memiliki 3 level hak akses: User (Owner), Group, dan Others.

Tabel Nilai Bobot Oktal Permission

r (Read) = Nilai 4
Izin membaca isi file atau melihat daftar isi folder.
w (Write) = Nilai 2
Izin mengedit, membuat, dan menghapus file/folder.
x (Execute) = Nilai 1
Izin menjalankan skrip/program atau masuk ke folder.
Contoh 'chmod 755 /var/www/html':
• Owner = 7 (4+2+1 = rwx : baca, tulis, eksekusi)
• Group = 5 (4+0+1 = r-x : baca & eksekusi)
• Others = 5 (4+0+1 = r-x : baca & eksekusi)
# Mengubah kepemilikan user & group file (chown)
sudo chown -R ahmad:webdev /var/www/html
sudo chmod -R 755 /var/www/html

3 Prinsip Least Privilege (Keamanan Server)

Prinsip Least Privilege (PoLP) menyatakan bahwa setiap user, program, atau layanan server hanya boleh diberikan hak akses minimum yang mutlak dibutuhkan untuk menjalankan tugasnya.

  • ❌ Hindari: Login langsung sebagai user root via SSH (nonaktifkan PermitRootLogin di sshd_config).
  • ❌ Hindari: Memberi permission chmod 777 pada folder publik web.
  • ✅ Gunakan: User biasa dengan perintah sudo spesifik yang tercatat di audit log (/var/log/auth.log).
