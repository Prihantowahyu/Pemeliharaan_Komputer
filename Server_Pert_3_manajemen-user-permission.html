1 Administrasi Pengguna & Grup di Linux Server

# 1. Membuat grup divisi teknisi & web developer
sudo groupadd sysadmin
sudo groupadd webdev

# 2. Membuat user baru dengan shell bash dan direktori home otomatis
sudo useradd -m -s /bin/bash -g webdev -G sudo ahmad
sudo passwd ahmad

# 3. Memeriksa identitas user (UID, GID, Groups)
id ahmad

2 Skema Perhitungan Hak Akses File (Octal Notation)

KarakterOperasiNilai BinerNilai Desimal
r (Read)Membaca isi file / melihat daftar direktori1004
w (Write)Mengubah, mengedit, atau menghapus file0102
x (Execute)Mengeksekusi program binary / memasuki folder (cd)0011
# Contoh Perhitungan Standar:
755 = (rwx=7) User Owner, (r-x=5) Group, (r-x=5) Others -> Cocok untuk Direktori & Script
644 = (rw-=6) User Owner, (r--=4) Group, (r--=4) Others -> Cocok untuk File Teks & Dokumen
700 = (rwx=7) User Owner saja, (---=0) yang lain dilarang -> File Sensitif / Kunci SSH

sudo chmod 755 /var/www/html
sudo chown -R ahmad:webdev /var/www/html

3 Konfigurasi Sudoers (/etc/sudoers via visudo)

Prinsip Least Privilege melarang membagikan password root. Berikan hak eksekusi perintah spesifik menggunakan utilitas aman sudo visudo:

# Menambahkan aturan ke file /etc/sudoers (Gunakan perintah visudo!)
# Mengizinkan anggota grup webdev merestart web server tanpa password:
%webdev ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart nginx, /usr/bin/systemctl reload nginx
