Pendahuluan & Apersepsi — Mengapa Dilarang Selalu Login Sebagai Root?
⏱ 08.00 – 08.30 · 30 Menit
▼

User root adalah penguasa mutlak di Linux yang dapat menghapus seluruh sistem tanpa konfirmasi (rm -rf /). Standar industri mewajibkan setiap administrator memiliki akun individu dengan hak sudo terbatas agar seluruh tindakan tercatat di audit log.

4
Praktikum Mandiri — Isolasi Folder Kolaborasi Tim (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
1
Buat group dan 2 user anggota tim:
sudo groupadd it_team
sudo useradd -m -s /bin/bash -g it_team andi
sudo useradd -m -s /bin/bash -g it_team budi
sudo passwd andi
sudo passwd budi
2
Buat folder kolaborasi dengan izin SGID (2770):
sudo mkdir -p /data/it_share
sudo chown root:it_team /data/it_share
sudo chmod 2770 /data/it_share
3
Beri hak sudo terbatas via visudo:
sudo visudo
# Tambahkan baris di paling bawah:
andi ALL=(ALL) /usr/bin/systemctl restart *
