1 Skenario & Alur Uji Tatap Muka UKK (9 JP / 405 Menit)

Fase 1: Pembukaan Resmi & Briefing Standar Asesmen BNSP 08.00 - 08.30 (30 Menit)

Penguji eksternal dan guru membacakan pakta integritas kejujuran asesmen, rubrik penilaian KKTP (Kriteria Ketercapaian Tujuan Pembelajaran), dan pembagian nomor workstation lab siswa.

Fase 2: Pembacaan Lembar Soal & Parameter Teknis UKK 08.30 - 09.30 (60 Menit)

Siswa membedah skenario tugas: Membangun server serbaguna mandiri dalam waktu 150 menit: DNS BIND9, Web HTTPS Nginx, Database MariaDB, dan Firewall UFW dengan toleransi downtime 0%.

Fase 3: Reset Lingkungan Lab ke Clean State (Fresh Boot) 09.30 - 10.30 (60 Menit)

Seluruh workstation di-reset ke status instalasi OS murni tanpa konfigurasi tersimpan sebelumnya. Siswa menyiapkan editor teks (nano/vim) dan utilitas CLI.

Istirahat Lab / Persiapan Mental 10.30 - 10.45 (15 Menit)

Penyegaran sebelum timer ujian praktikum 150 menit dimulai serentak.

Fase 4: Pelaksanaan Uji Mandiri Unjuk Kerja Real-Time (150 Menit) 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet UKK Final secara independen tanpa komunikasi antar-peserta: Menyusun seluruh rantai layanan server dari nol hingga siap diakses di portofolio.

Fase 5: Uji Petik Gangguan (Fault Injection oleh Penguji) 13.15 - 14.15 (60 Menit)

Penguji menginjeksikan 1 kerusakan sistem acak di server siswa (misal: mematikan service, merusak 1 baris config, atau memblokir port via firewall). Siswa wajib mendiagnosa dan memperbaiki kerusakan dalam waktu maksimal 15 menit!

Fase 6: Evaluasi Teori CBT, Sidang Hasil & Penyerahan Portofolio 14.15 - 15.00 (45 Menit)

Pengerjaan evaluasi teori CBT Final 30 menit, sidang pleno penetapan predikat KOMPETEN / BELUM KOMPETEN, dan penutupan seluruh kurikulum Kelas XII TKJ.

2 Matriks Rubrik Penilaian Asesmen UKK (Skor 0 - 100)

Komponen Uji KompetensiBobotIndikator Ketercapaian Maksimal
1. Konfigurasi Jaringan & Hostname10 PoinNetplan YAML valid, IP Statis aktif, DNS resolver berfungsi, FQDN sesuai ketentuan.
2. DNS Server BIND9 Master20 PoinZona Forward & Reverse resolve sempurna via dig, sintaks valid named-checkzone OK.
3. Web Server & SSL/TLS Enkripsi20 PoinVirtual Host HTTPS Port 443 aktif dengan sertifikat X.509, redirect 301 otomatis dari port 80.

5. Firewall Hardening & Security15 PoinUFW Default Deny Incoming aktif, hanya port resmi yang listening, SSH keypair terpasang.
6. Ketahanan Troubleshooting Kasus15 PoinMampu mengatasi fault injection penguji dalam waktu < 15 menit menggunakan analisis log.
