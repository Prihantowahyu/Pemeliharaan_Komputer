2 Standar Prosedur Pengujian Unjuk Kerja (Troubleshooting Kasus Acak)

# Penguji akan menyuntikkan 1-2 skenario kesalahan (fault injection): 1. Service BIND9 named.conf syntax error (titik koma hilang) 2. DocumentRoot permission tidak bisa dibaca www-data (chmod 700 root) 3. MySQL bind-address masih 127.0.0.1 sehingga koneksi client timeout 4. Firewall UFW memblokir port 443 HTTPS # Siswa wajib mendiagnosis dalam waktu < 15 menit menggunakan: sudo systemctl status [service] sudo journalctl -u [service] -e sudo ss -tulnp sudo ufw status verbose
