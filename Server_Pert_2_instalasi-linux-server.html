Instalasi Sistem Operasi Linux Server & Konfigurasi Awal

Panduan komprehensif instalasi Ubuntu Server / Debian, skema partisi LVM, pengaturan Static IP dengan Netplan, dan manajemen repositori paket APT.

1 Pemilihan Distro Server & Skema Partisi

Di lingkungan enterprise dan data center, Ubuntu Server LTS dan Debian Stable adalah dua distro Linux paling populer karena kestabilan kernel, dukungan jangka panjang (5 tahun), dan ekosistem repositori yang luas.

Skema Partisi Standar Server

  • /boot/efi (FAT32 ~512MB) — Bootloader UEFI
  • / (Root ext4 ~40GB+) — Sistem operasi dasar
  • /var (ext4 ~50GB+) — Log dan database
  • swap (2GB–4GB) — Virtual memory darurat

Keuntungan Menggunakan LVM

LVM (Logical Volume Manager) memungkinkan perluasan kapasitas partisi secara dinamis (*online resize*) tanpa perlu memformat atau mematikan server saat disk penuh.

2 Konfigurasi Hostname & Static IP (Netplan YAML)

Server wajib memiliki Alamat IP Statis (Static IP) agar client dan router selalu dapat menemukan layanan tanpa berubah-ubah.

File: /etc/netplan/00-installer-config.yaml
YAML Config
network:
  version: 2
  renderer: networkd
  ethernets:
    ens33:
      dhcp4: no
      addresses:
        - 192.168.10.1/24
      routes:
        - to: default
          via: 192.168.10.254
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]

Terapkan konfigurasi Netplan dan ganti Hostname server:

sudo hostnamectl set-hostname srv-tkj-utama
sudo netplan apply
ip a show ens33

3 Manajemen Repositori Paket (APT)

Setelah jaringan online, langkah penting pertama adalah memperbarui indeks paket dan kernel keamanan server:

# 1. Update daftar paket terbaru dari server cermin (mirror)
sudo apt update

# 2. Upgrade semua paket yang memiliki versi patch keamanan terbaru
sudo apt upgrade -y

# 3. Instal paket utilitas dasar sysadmin
sudo apt install -y curl wget git net-tools htop ufw
