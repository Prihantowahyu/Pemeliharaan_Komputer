1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Persiapan Media Instalasi 08.00 - 08.30 (30 Menit)

Guru mendemonstrasikan verifikasi integritas SHA256 checksum file ISO Ubuntu Server 22.04 LTS. Siswa memeriksa alokasi virtual hard disk (30 GB) di workstation/VirtualBox masing-masing dan menetapkan skema partisi server.

Fase 2: Pendalaman Teori LVM (Logical Volume Manager) 08.30 - 09.30 (60 Menit)

Pembedahan hierarki LVM: Physical Volume (PV) → Volume Group (VG) → Logical Volume (LV). Guru menjelaskan mengapa partisi statis tradisional (MBR/GPT kaku) sangat dihindari di server produksi karena tidak bisa di-resize saat disk penuh tanpa downtime.

Fase 3: Bedah Sintaks YAML Netplan & Penamaan FQDN 09.30 - 10.30 (60 Menit)

Analisis file konfigurasi /etc/netplan/01-netcfg.yaml. Memahami aturan wajib indentasi spasi 2-karakter (pantangan tombol TAB di YAML), deklarasi gateway4/routes, DNS nameservers, dan pengujian aman dengan netplan try.

Istirahat Lab / Refreshment 10.30 - 10.45 (15 Menit)

Istirahat sejenak dan review parameter IP lab yang diberikan guru.

Fase 4: Job Sheet Praktikum Mandiri Terbimbing 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet 2 secara individu/berpasangan: (1) Menjalankan proses instalasi Ubuntu Server, (2) Partisi LVM kustom: /boot (1GB ext4), vg_server/lv_root (15GB), vg_server/lv_var (10GB), (3) Set Hostname server1.smk.lan, (4) Konfigurasi IP Statis Netplan 192.168.10.10/24, dan (5) Uji koneksi internet gateway.

Fase 5: Skenario Kasus Gangguan (Troubleshooting Lab) 13.15 - 14.15 (60 Menit)

Siswa menyelesaikan 2 skenario error yang disimulasikan: Error "Invalid YAML syntax due to TAB indentation" saat netplan apply, dan kegagalan APT update akibat DNS salah arah.

Fase 6: Asesmen CBT & Refleksi Kompetensi 9 JP 14.15 - 15.00 (45 Menit)

Pengerjaan evaluasi teori CBT Anti-Cheat, checklist unjuk kerja LVM & Netplan oleh guru, serta penutupan sesi.

2 Anatomi Teknis LVM & Konfigurasi Netplan YAML

# 1. HIERARKI PERINTAH LVM CLI sudo pvcreate /dev/sda3 # Inisialisasi Physical Volume sudo vgcreate vg_system /dev/sda3 # Buat Volume Group penampung sudo lvcreate -L 15G -n lv_root vg_system # Buat Logical Volume root (/) sudo lvcreate -L 10G -n lv_var vg_system # Buat Logical Volume data (/var) # 2. CARA RESIZE / EXPAND DISK SECARA LIVE TANPA RESTART SERVER sudo lvextend -L +5G /dev/vg_system/lv_var sudo resize2fs /dev/vg_system/lv_var # Perluas filesystem ext4 secara online
# File: /etc/netplan/00-installer-config.yaml (WAJIB GUNAKAN SPASI, DILARANG TAB!) 
network:
  version: 2
  renderer: networkd
  ethernets:
    ens33:
      dhcp4: no
      addresses:
        - 192.168.10.10/24
      routes:
        - to: default
          via: 192.168.10.1
      nameservers:
        addresses:
          - 192.168.10.1
          - 8.8.8.8
        search:
          - smk.lan

4 Troubleshooting: Mengatasi Kesalahan Umum Instalasi & YAML

Gejala KesalahanPenyebab UtamaTindakan Diagnostik & Solusi
Invalid YAML at // line 7 column 6: found character that cannot start any token (\t)Terdapat karakter TAB di dalam file konfigurasi Netplan.Ganti semua TAB dengan 2 atau 4 spasi. Gunakan perintah cat -A /etc/netplan/*.yaml untuk mendeteksi tanda ^I (simbol tab tersembunyi).
Could not get lock /var/lib/dpkg/lock-frontendAda proses apt lain yang sedang berjalan di latar belakang (unattended-upgrades).Cek proses: ps aux | grep apt. Tunggu proses selesai atau jalankan sudo systemctl stop unattended-upgrades.
Interface tidak mendapat IP setelah netplan applyNama interface salah (misal: menuliskan eth0 padahal OS mengenali enp0s3 atau ens33).Ketik ip link untuk melihat nama interface fisik yang terdeteksi oleh kernel Linux.
