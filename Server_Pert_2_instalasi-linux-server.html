1 Konsep & Skema Partisi Enterprise: LVM vs Standar

Pada server produksi, partisi standar (MBR/GPT statis) dihindari karena tidak fleksibel saat kapasitas disk penuh. Logical Volume Manager (LVM) menambahkan lapisan abstraksi di atas storage fisik:

1. PV (Physical Volume)
Disk fisik mentah (seperti /dev/sda atau /dev/nvme0n1) yang diinisialisasi untuk LVM.
2. VG (Volume Group)
Kumpulan gabungan dari satu atau beberapa PV menjadi satu storage pool raksasa.
3. LV (Logical Volume)
Partisi virtual (seperti /dev/ubuntu-vg/ubuntu-lv) yang dapat diperbesar atau diperkecil secara live tanpa reboot.

2 Konfigurasi Static IP via Netplan YAML

Ubuntu Server menggunakan Netplan berbasis format YAML yang sensitif terhadap indentasi spasi (dilarang menggunakan TAB). Konfigurasi terletak di /etc/netplan/01-netcfg.yaml atau /etc/netplan/50-cloud-init.yaml:

# File: /etc/netplan/00-installer-config.yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: no
      addresses:
        - 192.168.10.1/24
      routes:
        - to: default
          via: 192.168.10.254
      nameservers:
        addresses:
          - 192.168.10.1
          - 8.8.8.8
          - 1.1.1.1
        search:
          - smk.lan
# Perintah menerapkan dan menguji konfigurasi Netplan
sudo netplan generate
sudo netplan apply
ip addr show enp0s3
ip route

3 Hostname Server & Update Repositori APT

# 2. Update Repositori Lokal Indonesia (Kambing / Datautama / Telkom)
