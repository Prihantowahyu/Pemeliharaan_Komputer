Konfigurasi File Sharing Server (Samba & NFS)

Menyediakan media penyimpanan terpusat (Shared Folder & Storage) yang dapat diakses bersama secara aman oleh client Windows (Samba/SMB) dan Linux (NFS).

1 Samba (SMB/CIFS) vs NFS: Kapan Digunakan?

Samba Server (SMB/CIFS)

Protokol berbagi file cross-platform. Sangat ideal untuk menghubungkan server Linux dengan client Windows Explorer (\\192.168.10.1\data) dan macOS dengan dukungan otentikasi user & hak baca/tulis.

NFS (Network File System)

Protokol native antar sistem Unix/Linux. Memiliki throughput sangat tinggi, latency rendah, dan file permission Linux (UID/GID) dipertahankan secara utuh.

2 Konfigurasi Samba Shared Folder (/etc/samba/smb.conf)

# 1. Instalasi paket Samba
sudo apt install -y samba

# 2. Buat folder dan set user Samba
sudo mkdir -p /srv/samba/data_tkj
sudo smbpasswd -a ahmad

# 3. Tambahkan konfigurasi di baris paling bawah /etc/samba/smb.conf
[DataTKJ]
   path = /srv/samba/data_tkj
   browsable = yes
   writable = yes
   valid users = ahmad, @webdev
   read only = no
   create mask = 0775
   directory mask = 0775
# 4. Restart layanan Samba
sudo systemctl restart smbd
