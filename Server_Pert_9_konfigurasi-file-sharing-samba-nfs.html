1 Perbandingan Protokol: Samba (SMB) vs NFS

AspekSamba (SMB/CIFS)NFS (Network File System)
Target ClientWindows, Linux, macOS (Universal)Unix/Linux saja
Port UtamaTCP 445, UDP 137-139TCP/UDP 2049 (NFSv3/v4)
AutentikasiUsername & Password (smbpasswd)UID/GID berdasarkan IP host (Trust-Based)
Performa LANBaik (optimal untuk Windows domain)Sangat cepat (overhead minimal sesama Linux)
Kasus PenggunaanShared folder enterprise, print serverStorage cluster, /home terpusat Linux farm

2 Konfigurasi Samba /etc/samba/smb.conf & NFS /etc/exports

# /etc/samba/smb.conf — Tambahkan share baru di bawah [global] [global] workgroup = SMKLAN server string = Samba Server SMK %v security = user map to guest = bad user [DataBersama] comment = Folder Bersama Kelas XII TKJ path = /srv/samba/databersama read only = no browsable = yes valid users = @smkgroup create mask = 0664 directory mask = 0775
# Buat user Samba & set password sudo groupadd smkgroup sudo mkdir -p /srv/samba/databersama sudo chown -R root:smkgroup /srv/samba/databersama sudo chmod 2775 /srv/samba/databersama sudo smbpasswd -a siswa01 sudo systemctl restart smbd nmbd
# /etc/exports — NFS Export Definition /srv/nfs/shared 192.168.10.0/24(rw,sync,no_subtree_check,no_root_squash) # Mount NFS di client Linux sudo mount -t nfs 192.168.10.1:/srv/nfs/shared /mnt/nfs_smk df -h | grep nfs
