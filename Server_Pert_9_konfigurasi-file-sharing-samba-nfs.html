Teori Komparasi: Samba (SMB/CIFS) vs NFSv4
⏱ 08.30 – 09.30 · 60 Menit
▼
Samba Server (SMB / CIFS)
  • Protokol: Server Message Block (SMB v2/v3)
  • Port: TCP 445 (Microsoft-DS) & NetBIOS UDP 137/138, TCP 139
  • Kelebihan: Kompatibilitas 100% dengan Windows, MacOS, Android, Linux
  • Autentikasi: Password database mandiri via smbpasswd
NFS (Network File System v4)
  • Protokol: NFSv4 (RFC 7530)
  • Port: TCP 2049
  • Kelebihan: Latensi sangat rendah, throughput tinggi antar sesama Linux/Unix
  • Autentikasi: Berbasis Subnet IP Client & UID/GID mapping

Bedah File Konfigurasi /etc/samba/smb.conf & /etc/exports
⏱ 09.30 – 10.30 · 60 Menit
▼

📄 Konfigurasi Share Samba (/etc/samba/smb.conf)

# Share 1: Folder Publik (Semua orang boleh membaca tanpa password)
[Publik_Materi]
    path = /srv/samba/publik
    browseable = yes
    read only = yes
    guest ok = yes

# Share 2: Folder Khusus Guru (Wajib Login & Boleh Menulis)
[Dokumen_Guru]
    path = /srv/samba/guru
    browseable = yes
    read only = no
    valid users = @guru_group, pak_wahyu
    create mask = 0660
    directory mask = 0770

📄 Konfigurasi NFS Export (/etc/exports)

# Format: [Folder_Lokal] [IP_Client_Diizinkan](Parameter)
/srv/nfs/data_cluster   192.168.10.0/24(rw,sync,no_subtree_check,no_root_squash)

Praktikum Mandiri — Deploy Samba & Map Network Drive (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
🎯 Target: Folder \\192.168.10.10\Dokumen_Guru dapat dimount di laptop Windows sebagai Drive Z: dengan autentikasi user Samba.
1
Install Samba & NFS Server:
sudo apt update && sudo apt install -y samba smbclient nfs-kernel-server
2
Buat folder penyimpanan fisik di Linux:
sudo mkdir -p /srv/samba/publik /srv/samba/guru /srv/nfs/data_cluster
sudo chmod -R 777 /srv/samba/publik
3
Buat group dan user Samba:
sudo groupadd guru_group
sudo useradd -M -s /usr/sbin/nologin pak_wahyu
sudo usermod -aG guru_group pak_wahyu
sudo smbpasswd -a pak_wahyu   # Set password khusus Samba
4
Atur Linux File Ownership:
sudo chown -R root:guru_group /srv/samba/guru
sudo chmod -R 2770 /srv/samba/guru   # 2=SGID bit agar file baru otomatis grup sama
5
Uji sintaks smb.conf & restart service:
testparm -s
sudo systemctl restart smbd nmbd nfs-kernel-server
sudo ufw allow samba
sudo ufw allow from 192.168.10.0/24 to any port nfs
6
Uji dari Laptop Windows (File Explorer):
  • Tekan Win + R → ketik \\192.168.10.10 → Enter
  • Muncul folder Publik_Materi dan Dokumen_Guru
  • Klik kanan Dokumen_Guru → Map network drive... → Pilih Drive Z:
  • Masukkan user: pak_wahyu dan password Samba
  • Coba buat file teks baru tugas_tkj.docx di dalam Drive Z:
7
Uji Mount NFS dari Client Linux:
sudo apt install nfs-common
sudo mkdir -p /mnt/cluster_storage
sudo mount -t nfs 192.168.10.10:/srv/nfs/data_cluster /mnt/cluster_storage
df -h | grep nfs

Troubleshooting: Dua Lapisan Izin (Two-Tier Permissions Conflict)
⏱ 13.15 – 14.15 · 60 Menit
▼
⚠️ Masalah Klasik Samba: Di file smb.conf disetel read only = no (Share Permission Boleh Tulis), TETAPI di sistem file Linux foldernya berstatus chmod 555 (Hanya Baca). Akibatnya: Client Windows mendapat error "Access Denied / Permission Denied" saat menyimpan file!
Lapisan IzinLokasi KonfigurasiSolusi Jika Konflik
Tier 1: Share PermissionFile /etc/samba/smb.conf (writable = yes)Buka akses tulis di deklarasi blok share
Tier 2: Linux File PermissionSistem file Linux (chmod & chown)Eksekusi: sudo chmod -R 775 /srv/samba/guru
