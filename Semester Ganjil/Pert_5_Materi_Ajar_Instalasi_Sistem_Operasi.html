Persiapan Media Instalasi Bootable
2 JP · teori + praktik

Sistem operasi (OS) adalah perangkat lunak dasar yang mengatur seluruh perangkat keras dan menjalankan aplikasi. Sebelum menginstal OS baru, dibutuhkan media instalasi berupa USB atau DVD yang bersifat bootable — dapat dijalankan langsung saat komputer dinyalakan, sebelum masuk ke sistem operasi.

▸ Jenis Media Instalasi

MediaKarakteristik
DVD BootableMulai jarang dipakai karena laptop modern tanpa optical drive
USB BootableStandar saat ini — cepat dan dapat dipakai berulang

File ISO adalah "cetakan" utuh dari sebuah CD/DVD instalasi, berisi seluruh data OS dalam satu file tunggal (.iso). ISO Windows diunduh dari Microsoft, ISO Linux (misal Ubuntu/Linux Mint) diunduh dari situs resmi distro.

▸ Software Pembuat Bootable

SoftwareOS TargetKeterangan
RufusWindowsRingan, cepat, banyak dipakai di Indonesia
BalenaEtcherWindows & LinuxLintas platform, tampilan sederhana
Media Creation ToolWindows sajaResmi dari Microsoft

▸ Konsep BIOS/UEFI & Boot Mode

Mode Legacy (BIOS) dan UEFI memengaruhi skema partisi yang digunakan (MBR vs GPT). Fitur Secure Boot pada beberapa laptop perlu dinonaktifkan sementara agar instalasi Linux tertentu dapat berjalan.

▸ Langkah Praktik: Membuat USB Bootable (Rufus)

  1. Colokkan USB flashdisk (data akan terhapus — pastikan sudah dibackup)
  2. Buka aplikasi Rufus
  3. Pilih Device = USB flashdisk yang digunakan
  4. Pilih Boot selection → SELECT → arahkan ke file ISO
  5. Pilih skema partisi: GPT (UEFI) atau MBR (Legacy BIOS)
  6. Klik START, tunggu selesai — jangan cabut USB selama proses
  7. Verifikasi USB berisi file instalasi lewat File Explorer
📋 Aktivitas: setiap siswa membuat 1 USB bootable ✅ Penilaian: observasi langsung proses

▸ Mode Instalasi

ModeKeterangan
Clean InstallMenghapus seluruh isi disk, instalasi bersih
UpgradeMempertahankan data/aplikasi lama
Dual BootWindows berdampingan dengan OS lain

▸ Langkah Instalasi Windows

  1. Atur Boot Priority di BIOS/UEFI agar boot dari USB
  2. Pilih Bahasa, Waktu, Keyboard → Next → Install Now
  3. Masukkan/lewati Product Key, pilih edisi Windows, setujui lisensi
  4. Pilih Custom: Install Windows only (advanced)
  5. Hapus partisi lama (jika clean install) dengan Delete, buat partisi baru dengan New
  6. Tunggu proses copying files, installing features, hingga finishing up (restart otomatis)
  7. Isi Out-of-Box Experience: wilayah, keyboard, jaringan, akun pengguna
  8. Sistem masuk ke Desktop Windows
!
PERHATIANTahap partisi disk tidak dapat dibatalkan setelah data dihapus. Gunakan disk latihan/kosong, bukan disk berisi data penting.

Instalasi Linux Desktop
3 JP · praktik instalasi

Linux adalah sistem operasi open source. Distro yang umum untuk pemula: Ubuntu, Linux Mint, Zorin OS. Tampilan antarmuka (desktop environment) mirip Windows sehingga mudah dipelajari pemula.

▸ Mode Instalasi Linux

ModeKeterangan
Try/Live ModeMencoba Linux tanpa instalasi (berjalan dari USB)
Single BootLinux sebagai satu-satunya OS, menghapus seluruh disk
Dual BootBerdampingan dengan Windows yang sudah ada, memakai sisa ruang disk

▸ Pengenalan Partisi Linux

PartisiFungsi
/ (root)Partisi sistem utama
/homeData & pengaturan pengguna
swapMemori virtual (opsional pada sistem modern)
/boot/efiBoot loader untuk UEFI

▸ Langkah Instalasi Linux (Ubuntu/Linux Mint)

  1. Boot dari USB Linux → pilih Try or Install
  2. Pilih bahasa pengantar & layout keyboard
  3. Pilih jenis instalasi: Install alongside Windows (dual boot), Erase disk (single boot), atau Something else (manual)
  4. Bila dual boot, geser slider pembagian ruang disk
  5. Pilih zona waktu, buat akun pengguna (nama, username, password)
  6. Klik Install Now → konfirmasi perubahan partisi
  7. Tunggu proses instalasi & pemasangan boot loader GRUB
  8. Restart, cabut USB, pilih OS di GRUB Boot Menu (jika dual boot)
  9. Verifikasi berhasil masuk ke Desktop Linux
!
PERHATIANPada dual boot, salah memilih target partisi dapat menghapus Windows yang sudah terinstal. Guru wajib mendampingi tahap pemilihan partisi.
📋 Aktivitas: instalasi single boot / dual boot sesuai kondisi unit ✅ Penilaian: keberhasilan boot Live USB & sistem masuk ke desktop
