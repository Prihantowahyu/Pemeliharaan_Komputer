Bagian 1

1. Tabel Partisi: GPT (GUID Partition Table) vs MBR (Master Boot Record)

Pemilihan skema partisi menentukan kapasitas maksimal storage dan kompatibilitas firmware UEFI.

GPT (Modern · Rekomendasi Utama)

  • Kapasitas Maksimal: Hingga 9.4 Zettabytes (9.4 miliar Terabytes).
  • Jumlah Partisi Primer: Hingga 128 partisi primer tanpa perlu partisi extended.
  • Keamanan: Memiliki tabel partisi cadangan (Backup Header) di akhir disk untuk recovery otomatis jika sektor awal korup.
  • Firmware Wajib: UEFI Mode (Native 64-bit).

MBR (Legacy · Kompatibilitas Lama)

  • Kapasitas Maksimal: Terbatas maksimal 2 Terabytes (2 TB per disk).
  • Jumlah Partisi Primer: Maksimal 4 partisi primer (atau 3 primer + 1 extended).
  • Keamanan: Struktur header tunggal di sektor 0; jika korup, seluruh partisi hilang.
  • Firmware: Legacy BIOS / CSM Mode.
Bagian 2

2. Analisis Parameter S.M.A.R.T. Kesehatan Disk (HDD/SSD)

S.M.A.R.T. (Self-Monitoring, Analysis, and Reporting Technology) memberikan peringatan dini sebelum media penyimpanan rusak total.

05 · Reallocated Sectors Count

Jumlah sektor bad sector fisik yang telah direlokasi ke area cadangan. Jika angka raw value bernilai > 0 pada HDD, disk berisiko tinggi dan data wajib segera dibackup!

C5 · Current Pending Sector Count

Sektor yang mengalami error pembacaan dan menunggu pengujian ulang/realokasi. Tanda awal kerusakan piringan magnetik.

05 / E7 · SSD Wear Range Delta / Life Remaining

Persentase sisa ketahanan sel NAND flash SSD berdasarkan TBW (Terabytes Written). 100% = baru, < 10% = sel mendekati masa akhir pakai.
