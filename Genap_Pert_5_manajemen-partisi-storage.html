Skema partisi adalah fondasi infrastruktur data di setiap disk. Pemilihan yang salah dapat mengakibatkan batasan kapasitas atau ketidakcocokan dengan firmware sistem.

S.M.A.R.T. (Self-Monitoring, Analysis, and Reporting Technology) adalah sistem pelaporan kesehatan internal HDD/SSD. Memahami atribut kritisnya dapat mencegah kehilangan data dengan memberikan peringatan 48-72 jam sebelum kegagalan total.

Bagian C · Optimasi SSD

C. Optimasi SSD: TRIM, Over-Provisioning & Wear Leveling

SSD memiliki karakteristik berbeda dari HDD yang memerlukan penanganan khusus agar tetap cepat dan awet dalam jangka panjang.

TRIM: Mekanisme Pembersih SSD

Ketika file dihapus di Windows, SSD tidak langsung menghapus data fisik dari sel NAND. TRIM memberi tahu SSD bahwa blok tertentu sudah tidak digunakan dan boleh dihapus saat idle, menjaga kecepatan tulis tetap optimal.

Verifikasi TRIM aktif: Buka CMD Admin → ketik: fsutil behavior query DisableDeleteNotify. Hasil 0 = TRIM AKTIF (normal). Hasil 1 = TRIM dinonaktifkan (perlu perbaikan).

Over-Provisioning: Cadangan Ruang Tersembunyi

Produsen SSD menyisihkan 7-28% kapasitas NAND sebagai cadangan tersembunyi (tidak terlihat OS) untuk menggantikan sel yang rusak dan menyediakan buffer untuk operasi wear leveling. Ini sebabnya SSD 480GB terasa lebih cepat dan awet dari SSD 500GB.

Jangan Defragmentasi SSD!

Defragmentasi (defrag) dirancang untuk HDD mekanik yang memiliki "jarak fisik" antar sektor. Pada SSD, semua lokasi diakses dalam waktu sama (no latency). Defrag justru MERUSAK SSD karena menambah write cycle yang tidak perlu dan mempercepat degradasi sel NAND.

Windows secara otomatis tidak men-defrag SSD — ia hanya menjalankan TRIM/Optimize pada SSD.

Menjalankan CHKDSK untuk Deteksi Bad Sector

Buka CMD sebagai Administrator: chkdsk C: /f /r /x. Parameter /f (fix errors), /r (locate bad sectors dan recovery data), /x (force dismount jika perlu). Proses berjalan saat restart berikutnya jika drive sedang digunakan.

Verifikasi Integritas File Sistem dengan SFC

Jalankan sfc /scannow di CMD Administrator untuk memindai dan memperbaiki file sistem Windows yang rusak atau tergantikan oleh malware. Dilanjutkan dengan DISM /Online /Cleanup-Image /RestoreHealth jika SFC menemukan masalah yang tidak bisa diperbaiki sendiri.
