1 Konfigurasi Firewall ufw & iptables

# ── UFW (Uncomplicated Firewall) — Antarmuka mudah untuk iptables ── sudo ufw default deny incoming # Blokir semua koneksi masuk secara default sudo ufw default allow outgoing # Izinkan semua koneksi keluar sudo ufw allow 2222/tcp # Izinkan SSH port kustom sudo ufw allow 80/tcp # HTTP sudo ufw allow 443/tcp # HTTPS sudo ufw allow from 192.168.10.0/24 to any port 3306 # MySQL — hanya dari LAN sudo ufw enable sudo ufw status verbose # ── iptables langsung — Drop port scanning (SYN flood protection) ── sudo iptables -A INPUT -p tcp --tcp-flags ALL NONE -j DROP sudo iptables -A INPUT -p tcp ! --syn -m state --state NEW -j DROP sudo iptables -A INPUT -p tcp --tcp-flags ALL ALL -j DROP

2 Server Hardening Checklist & SSL/TLS Self-Signed

Kategori HardeningTindakanPerintah / Konfigurasi
System UpdatePatch semua package ke versi terbarusudo apt update && sudo apt upgrade -y
Disable unused servicesNonaktifkan layanan yang tidak dipakaisudo systemctl disable avahi-daemon cups
File permissionsAtur SUID/SGID berbahayafind / -perm /6000 -type f 2>/dev/null
Kernel hardeningTerapkan sysctl security paramsecho "net.ipv4.ip_forward=0" >> /etc/sysctl.conf
# Generate sertifikat SSL Self-Signed (untuk lab internal) sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \ -keyout /etc/ssl/private/smk.key \ -out /etc/ssl/certs/smk.crt \ -subj "/C=ID/ST=Jatim/L=Surabaya/O=SMK/CN=smk.lan" # Aktifkan SSL di Apache sudo a2enmod ssl sudo a2ensite default-ssl sudo systemctl reload apache2 curl -k https://smk.lan # Uji HTTPS (dengan -k untuk skip verifikasi self-signed)
