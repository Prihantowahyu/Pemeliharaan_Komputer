2
Arsitektur Firewall: Prinsip 'Default Deny' Incoming Traffic
⏱ 08.30 – 09.30 · 60 Menit
▼
🔒 Aturan Emas Firewall: Blokir SEMUA koneksi masuk dari luar (Default Deny), lalu buka HANYA port resmi yang dibutuhkan sistem (Whitelist Principle)! 
# Kebijakan Default UFW:
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 2222/tcp  # SSH Port Khusus
sudo ufw allow 80/tcp    # HTTP Web
sudo ufw allow 443/tcp   # HTTPS Enkripsi
sudo ufw enable

4
Praktikum Mandiri — Generate Self-Signed SSL & VHost HTTPS (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
1
Generate Private Key RSA 2048-bit & Sertifikat X.509:
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/portal.key \
  -out /etc/ssl/certs/portal.crt \
  -subj "/C=ID/ST=JawaTengah/L=Surakarta/O=SMK Negeri 1/CN=portal.smk.lan"
2
Konfigurasi Virtual Host Apache HTTPS Port 443:
sudo nano /etc/apache2/sites-available/portal-ssl.conf
# Konfigurasi:
<VirtualHost *:443>
    ServerName portal.smk.lan
    DocumentRoot /var/www/portal
    SSLEngine on
    SSLCertificateFile /etc/ssl/certs/portal.crt
    SSLCertificateKeyFile /etc/ssl/private/portal.key
</VirtualHost>
3
Aktifkan modul SSL & VHost:
sudo a2enmod ssl
sudo a2ensite portal-ssl.conf
sudo systemctl reload apache2
4
Uji Browser Client: Buka https://portal.smk.lan → Muncul gembok aman hijau/terenkripsi.
