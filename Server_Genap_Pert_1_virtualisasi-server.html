1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Efisiensi Server Konsolidasi 08.00 - 08.30 (30 Menit)

Apersepsi: Mengapa perusahaan beralih dari 10 server fisik yang boros listrik menjadi 1 server fisik berdaya besar yang menjalankan 10 Virtual Machine? Guru memaparkan efisiensi konsolidasi server dan penghematan CapEx/OpEx.

Fase 2: Arsitektur Hypervisor Tipe 1 (Bare-Metal) vs Tipe 2 (Hosted) 08.30 - 09.30 (60 Menit)

Analisis komparatif: Hypervisor Tipe 1 (Proxmox VE/ESXi) berjalan langsung di atas hardware fisik tanpa OS perantara (kinerja mendekati native 98%), sedangkan Tipe 2 (VirtualBox) berjalan di atas OS host Windows/Linux.

Fase 3: Mode Jaringan Virtual (NAT, Bridged, Host-Only, Internal) 09.30 - 10.30 (60 Menit)

Membedah 4 mode jaringan VM: Kapan menggunakan Bridged Adapter agar VM mendapat IP langsung dari router lab seolah-olah PC fisik, dan kapan menggunakan Internal Network untuk mengisolasi cluster lab privat.

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Persiapan BIOS komputer lab (memastikan opsi Intel VT-x / AMD-V aktif).

Fase 4: Job Sheet Praktikum Mandiri — Deploy & Automasi VM CLI 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet Genap 1: (1) Membuat 2 unit VM Linux Server via antarmuka CLI VBoxManage tanpa menyentuh mouse, (2) Konfigurasi 2 vCPU, 2048MB RAM, 20GB Dynamic VDI, (3) Pasang Bridged Adapter, (4) Buat Snapshot "Clean-OS-State", (5) Uji coba restore snapshot dalam 5 detik saat OS disimulasikan rusak.

Fase 5: Skenario Kasus Gangguan (Troubleshooting Nested Virtualization & MAC Conflict) 13.15 - 14.15 (60 Menit)

Siswa memecahkan error: "VT-x is not available in host", kendala kloning VM yang menghasilkan duplikasi MAC Address sama (IP conflict), serta alokasi RAM overcommitment.

Fase 6: Evaluasi CBT & Refleksi 9 JP 14.15 - 15.00 (45 Menit)

Pengerjaan evaluasi teori CBT 30 menit, checklist pengujian VM CLI oleh guru, dan pengantar materi Database Server MySQL/PostgreSQL untuk pertemuan ke-2.

# Otomasi Pembuatan Virtual Machine via CLI Headless (VBoxManage) VBoxManage createvm --name "Server-Web-Node1" --ostype "Ubuntu_64" --register VBoxManage modifyvm "Server-Web-Node1" --cpus 2 --memory 2048 --vram 16 --nic1 bridged --bridgeadapter1 "eth0" VBoxManage createmedium disk --filename "Server-Web-Node1.vdi" --size 20480 --format VDI VBoxManage storagectl "Server-Web-Node1" --name "SATA Controller" --add sata --controller IntelAhci VBoxManage storageattach "Server-Web-Node1" --storagectl "SATA Controller" --port 0 --device 0 --type hdd --medium "Server-Web-Node1.vdi" VBoxManage startvm "Server-Web-Node1" --type headless
