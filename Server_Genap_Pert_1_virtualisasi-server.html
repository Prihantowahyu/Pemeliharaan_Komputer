2
Teori Hypervisor: Type 1 (Bare-Metal) vs Type 2 (Hosted)
⏱ 08.30 – 09.30 · 60 Menit
▼
Type 1: Bare-Metal Hypervisor (Enterprise)
  • Hypervisor diinstall langsung di atas hardware fisik tanpa ada OS perantara
  • Performa 99% mendekati native hardware, latensi sangat rendah
  • Contoh industri: Proxmox VE, VMware ESXi, Microsoft Hyper-V Server, KVM
Type 2: Hosted Hypervisor (Testing / Lab)
  • Hypervisor berjalan sebagai aplikasi di atas Host OS (Windows / Ubuntu Desktop)
  • Terdapat overhead resource sistem operasi induk
  • Contoh: VirtualBox, VMware Workstation, QEMU

Praktikum Mandiri — Otomatisasi VM via VBoxManage CLI (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
🎯 Target: Siswa membuat, mengonfigurasi RAM/CPU/Network, dan menyalakan Virtual Machine headless tanpa menyentuh mouse sama sekali!
1
Buat VM baru dan daftarkan ke Hypervisor:
VBoxManage createvm --name "Server-Debian-12" --ostype "Debian_64" --register
2
Alokasikan 2 Core CPU, 2048MB RAM, dan Kartu Jaringan Bridged:
VBoxManage modifyvm "Server-Debian-12" --cpus 2 --memory 2048 --vram 16
VBoxManage modifyvm "Server-Debian-12" --nic1 bridged --bridgeadapter1 "Realtek PCIe GbE Family Controller"
3
Buat Virtual Disk SATA 20GB:
VBoxManage createhd --filename "Server-Debian-12.vdi" --size 20480
VBoxManage storagectl "Server-Debian-12" --name "SATA Controller" --add sata --controller IntelAhci
VBoxManage storageattach "Server-Debian-12" --storagectl "SATA Controller" --port 0 --device 0 --type hdd --medium "Server-Debian-12.vdi"
4
Start VM dalam mode Headless (di background):
VBoxManage startvm "Server-Debian-12" --type headless
VBoxManage list runningvms

Snapshot Management & Penanganan MAC Address Conflict
⏱ 13.15 – 14.15 · 60 Menit
▼

Membuat snapshot sebelum uji coba berbahaya, lalu rollback dalam 2 detik:

VBoxManage snapshot "Server-Debian-12" take "Clean_State_Sebelum_Uji"
# Jika VM rusak, lakukan rollback instan:
VBoxManage controlvm "Server-Debian-12" poweroff
VBoxManage snapshot "Server-Debian-12" restore "Clean_State_Sebelum_Uji"
