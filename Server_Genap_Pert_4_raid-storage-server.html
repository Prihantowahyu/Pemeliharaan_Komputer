Pendahuluan & Apersepsi — Semua Hard Disk Pasti Akan Rusak!
⏱ 08.00 – 08.30 · 30 Menit
▼

Hard disk mekanis (HDD) dan chip SSD memiliki masa pakai terbatas (MTBF). Pada server produksi, kita tidak boleh menunggu disk rusak baru panik. RAID (Redundant Array of Independent Disks) menggabungkan beberapa disk fisik menjadi satu drive logis dengan toleransi kegagalan (Fault Tolerance).

Arsitektur Linux Software RAID: Perintah mdadm & /proc/mdstat
⏱ 09.30 – 10.30 · 60 Menit
▼

Di Linux, array RAID dikelola oleh modul kernel Multiple Devices (md) yang dikenali sebagai device /dev/md0.

# Memeriksa status kesehatan RAID secara real-time:
cat /proc/mdstat

4
Praktikum Mandiri — Membangun RAID 5 Array + Hot Spare (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
1
Install utilitas mdadm:
sudo apt update && sudo apt install -y mdadm
2
Buat Array RAID 5 (3 Active Disk + 1 Hot Spare):
sudo mdadm --create --verbose /dev/md0 --level=5 --raid-devices=3 /dev/sdb /dev/sdc /dev/sdd --spare-devices=1 /dev/sde
3
Format dan Mount RAID Array:
sudo mkfs.ext4 /dev/md0
sudo mkdir -p /mnt/raid_storage
sudo mount /dev/md0 /mnt/raid_storage
4
Simpan konfigurasi permanen agar tidak hilang saat reboot:
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
sudo update-initramfs -u
5
Simulasi Kerusakan Disk (Fault Injection) & Automatic Rebuild
⏱ 13.15 – 14.15 · 60 Menit
▼

Siswa mensimulasikan salah satu hard disk rusak secara tiba-tiba, dan menyaksikan Hot Spare mengambil alih otomatis:

# 1. Tandai disk /dev/sdb sebagai 'FAILED' secara sengaja:
sudo mdadm --manage /dev/md0 --fail /dev/sdb

# 2. Pantau proses Rebuilding otomatis ke Hot Spare (/dev/sde):
watch -n 1 cat /proc/mdstat

# 3. Lepas disk rusak dan masukkan disk baru:
sudo mdadm --manage /dev/md0 --remove /dev/sdb
sudo mdadm --manage /dev/md0 --add /dev/sdf
