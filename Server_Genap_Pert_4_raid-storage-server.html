1 Perbandingan Level RAID

RAID LevelMin. DiskKapasitas EfektifToleransi FailureKasus Penggunaan
RAID 0 (Striping)2100% total disk❌ 0 disk (tidak ada redundansi)Video editing, scratch disk — performa maksimal
RAID 1 (Mirroring)250% total disk✅ 1 disk (mirror)Boot drive OS, database kritis — keamanan data
RAID 5 (Parity)3(N-1) × disk size✅ 1 disk (rebuild dari parity)NAS, file server — keseimbangan kapasitas & redundansi
RAID 10 (1+0)450% total disk✅ 1 disk per mirror pairDatabase produksi — performa + redundansi terbaik

2 Konfigurasi Software RAID 1 dengan mdadm

# 1. Buat RAID 1 (mirror) dari 2 disk: /dev/sdb dan /dev/sdc sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc # 2. Pantau proses sinkronisasi awal (resync) watch cat /proc/mdstat # 3. Buat filesystem dan mount array RAID sudo mkfs.ext4 /dev/md0 sudo mkdir /mnt/raid1 sudo mount /dev/md0 /mnt/raid1 # 4. Simpan konfigurasi agar persistent setelah reboot sudo mdadm --detail --scan >> /etc/mdadm/mdadm.conf sudo update-initramfs -u # 5. Simulasi disk failure — tandai disk sebagai failed sudo mdadm /dev/md0 --fail /dev/sdc sudo mdadm /dev/md0 --remove /dev/sdc # 6. Tambahkan disk pengganti (hot spare) sudo mdadm /dev/md0 --add /dev/sdd watch cat /proc/mdstat # Pantau rebuild otomatis
