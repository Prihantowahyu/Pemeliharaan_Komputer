Konfigurasi Mail Server Enterprise (Postfix SMTP & Dovecot IMAP/POP3)

Panduan terpadu membangun server email mandiri: Membedah arsitektur MUA (Mail User Agent), MTA (Mail Transfer Agent - Postfix Port 25/587), dan MDA (Mail Delivery Agent - Dovecot Port 143/993), konfigurasi format mailbox modern Maildir/ (satu file per pesan), integrasi antarmuka Webmail Roundcube, pengujian kirim/terima pesan lokal, serta proteksi Open Relay.

1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Alur Pengiriman Surat Elektronik 08.00 - 08.30 (30 Menit)

Apersepsi: Bagaimana email dikirim dari budi@smk.lan ke guru@smk.lan? Guru menguraikan 3 aktor utama: MUA (Thunderbird/Webmail), MTA (Postfix - pengantar paket SMTP), dan MDA (Dovecot - kotak pos IMAP/POP3).

Fase 2: Konfigurasi Postfix MTA (/etc/postfix/main.cf) 08.30 - 09.30 (60 Menit)

Pembedahan parameter inti: myhostname = mail.smk.lan, mydomain = smk.lan, myorigin = $mydomain, mydestination, mynetworks (mencegah server disalahgunakan sebagai spambot / Open Relay), dan home_mailbox = Maildir/.

Fase 3: Konfigurasi Dovecot MDA & Protokol IMAP vs POP3 09.30 - 10.30 (60 Menit)

Memahami perbedaan IMAP (Port 143/993: pesan tersimpan sinkron di server) vs POP3 (Port 110/995: pesan diunduh lalu dihapus dari server). Konfigurasi /etc/dovecot/conf.d/10-mail.conf dan 10-auth.conf.

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Persiapan akun user pengirim dan penerima email di server masing-masing.

Fase 4: Job Sheet Praktikum Mandiri — Deploy Mail Server & Webmail 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet 8: (1) Install postfix dovecot-imapd dovecot-pop3d, (2) Konfigurasi Postfix & Dovecot dengan format Maildir, (3) Uji kirim email via Telnet/Netcat di port 25, (4) Install Webmail Roundcube di Apache (http://mail.smk.lan/webmail), (5) Kirim pesan email dari user siswa1 ke guru1 disertai lampiran file.

Fase 5: Skenario Troubleshooting: Relay Access Denied & Mail Delivery Failed 13.15 - 14.15 (60 Menit)

Investigasi log sistem email di /var/log/mail.log saat terjadi penolakan relay, kegagalan autentikasi SASL, atau permission folder Maildir yang tidak terbaca oleh Dovecot.

Fase 6: Evaluasi CBT & Refleksi 9 JP 14.15 - 15.00 (45 Menit)

Pengerjaan evaluasi teori CBT 30 menit, checklist pengujian kirim/terima webmail oleh guru, dan pengantar materi File Sharing Samba & NFS.

2 Konfigurasi Lengkap Postfix & Dovecot

# 1. /etc/postfix/main.cf — MTA Configuration 
myhostname = mail.smk.lan
mydomain = smk.lan
myorigin = $mydomain
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
relayhost = 
mynetworks = 127.0.0.0/8 [::ffff:127.0.0.0]/104 [::1]/128 192.168.10.0/24
mailbox_size_limit = 0
recipient_delimiter = +
inet_interfaces = all
inet_protocols = all

# Wajib gunakan Maildir (satu file per email, lebih tahan korupsi dibanding mbox)
home_mailbox = Maildir/
# 2. /etc/dovecot/conf.d/10-mail.conf & 10-auth.conf — MDA Configuration 
mail_location = maildir:~/Maildir
disable_plaintext_auth = no
auth_mechanisms = plain login
