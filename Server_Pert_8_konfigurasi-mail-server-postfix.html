📂 Perbedaan Format Penyimpanan: mbox vs Maildir

Format Klasik: mbox (Single File)
  • Semua email disimpan dalam 1 file besar tunggal: /var/mail/username
  • Rentan File Locking Deadlock saat 2 proses membaca/menulis bersamaan
  • Jika 1 email korup, seluruh kotak surat bisa rusak
Format Modern: Maildir/ (Multi-File Directory)
  • Setiap 1 email disimpan sebagai 1 file individual di folder ~/Maildir/
  • Memiliki 3 subfolder: cur/ (dibaca), new/ (belum dibaca), tmp/
  • Bebas locking conflict, cepat, aman, dan standar industri modern

📄 Konfigurasi Inti Postfix (/etc/postfix/main.cf)

# File: /etc/postfix/main.cf
myhostname = mail.smk.lan
mydomain = smk.lan
myorigin = $mydomain
inet_interfaces = all
inet_protocols = ipv4
mydestination = $myhostname, localhost.$mydomain, $mydomain, localhost

# Mencegah Open Relay (Hanya subnet lab yang boleh kirim email tanpa auth)
mynetworks = 127.0.0.0/8, 192.168.10.0/24

# Wajib format Maildir dengan tanda garis miring di akhir!
home_mailbox = Maildir/
mailbox_size_limit = 0
recipient_delimiter = +

📄 Konfigurasi Inti Dovecot (/etc/dovecot/conf.d/)

# 1. /etc/dovecot/dovecot.conf -> Aktifkan protokol IMAP & POP3
protocols = imap pop3 lmtp

# 2. /etc/dovecot/conf.d/10-mail.conf -> Samakan format mailbox dengan Postfix
mail_location = maildir:~/Maildir

# 3. /etc/dovecot/conf.d/10-auth.conf -> Izinkan autentikasi plaintext di jaringan lokal
disable_plaintext_auth = no
auth_mechanisms = plain login

📋 8 Langkah Eksekusi Praktikum Lab

1
Install Postfix & Dovecot:
sudo DEBIAN_FRONTEND=noninteractive apt update && sudo apt install -y postfix dovecot-imapd dovecot-pop3d mailutils
2
Buat template Maildir otomatis untuk user baru di /etc/skel:
sudo maildirmake.dovecot /etc/skel/Maildir
sudo maildirmake.dovecot /etc/skel/Maildir/.Sent
sudo maildirmake.dovecot /etc/skel/Maildir/.Trash
3
Buat 2 akun pengirim dan penerima:
sudo adduser siswa1
sudo adduser guru
4
Terapkan konfigurasi Postfix & Dovecot:
sudo postconf -e "home_mailbox = Maildir/"
sudo postconf -e "mydomain = smk.lan"
sudo postconf -e "myhostname = mail.smk.lan"
sudo postconf -e "mydestination = \$myhostname, localhost.\$mydomain, \$mydomain, localhost"
sudo postconf -e "mynetworks = 127.0.0.0/8, 192.168.10.0/24"
5
Restart semua layanan email:
sudo systemctl restart postfix dovecot
sudo ss -tulnp | grep -E ':(25|143|110)'
6
Kirim email percobaan via CLI mailutils:
echo "Halo Bapak Guru, ini laporan tugas jaringan." | mail -s "Tugas TKJ Siswa 1" guru@smk.lan
7
Cek berkas email di direktori Maildir penerima:
ls -la /home/guru/Maildir/new/
cat /home/guru/Maildir/new/*
8
Uji interaktif via Telnet / Netcat ke Port SMTP 25:
telnet 127.0.0.1 25
HELO mail.smk.lan
MAIL FROM: <siswa1@smk.lan>
RCPT TO: <guru@smk.lan>
DATA
Subject: Uji Telnet SMTP
Pesan dari telnet port 25.
.
QUIT
