Konfigurasi Mail Server Postfix + Dovecot (IMAP/POP3 & Maildir)

Membangun sistem email enterprise internal menggunakan Postfix sebagai MTA (Mail Transfer Agent) dan Dovecot sebagai IMAP/POP3 mail retrieval agent, dengan format penyimpanan Maildir untuk skalabilitas tinggi.

1 Arsitektur Komponen Sistem Email

KomponenSingkatan & PeranSoftware yang DigunakanProtokol
MTAMail Transfer Agent — Antar-server relay emailPostfix, Sendmail, EximSMTP (Port 25, 587)
MDAMail Delivery Agent — Menyimpan email ke mailbox userProcmail, Maildrop, Dovecot LDAInternal delivery
MUAMail User Agent — Antarmuka baca tulis email end-userThunderbird, Roundcube, muttIMAP (143) / POP3 (110)

2 Konfigurasi Postfix (/etc/postfix/main.cf)

# /etc/postfix/main.cf — Postfix MTA enterprise local myhostname = mail.smk.lan mydomain = smk.lan myorigin = $mydomain inet_interfaces = all inet_protocols = ipv4 mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain mynetworks = 127.0.0.0/8, 192.168.10.0/24 # Format penyimpanan email Maildir (satu file per pesan) home_mailbox = Maildir/ # Ukuran mailbox max per user (bytes): 100 MB mailbox_size_limit = 104857600 message_size_limit = 10485760
# Konfigurasi Dovecot untuk IMAP/POP3 (/etc/dovecot/dovecot.conf) protocols = imap pop3 mail_location = maildir:~/Maildir disable_plaintext_auth = no auth_mechanisms = plain login
