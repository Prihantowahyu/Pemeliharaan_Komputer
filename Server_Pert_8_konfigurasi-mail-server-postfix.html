Konfigurasi Mail Server Dasar (Postfix SMTP & Dovecot)

Membangun sistem pengiriman dan penerimaan surat elektronik internal menggunakan Postfix (SMTP), Dovecot (IMAP/POP3), serta format penyimpanan Maildir.

1 3 Komponen Utama Arsitektur Email

1. MTA (Mail Transfer Agent)

Mengirim dan merutekan email antar-server melalui protokol SMTP (Port 25/587). Contoh: Postfix, Exim.

2. MDA / MRA (Mail Delivery Agent)

Menyimpan email ke kotak surat user dan melayani pengambilan via IMAP (Port 143/993) / POP3 (Port 110). Contoh: Dovecot.

3. MUA (Mail User Agent)

Aplikasi pembaca email di perangkat client (Mozilla Thunderbird, Outlook, Roundcube Webmail).

2 Konfigurasi Postfix (/etc/postfix/main.cf)

# 1. Instalasi Postfix & Mailutils
sudo apt install -y postfix mailutils dovecot-imapd dovecot-pop3d

# 2. Konfigurasi /etc/postfix/main.cf
myhostname = mail.smk.lan
mydomain = smk.lan
myorigin = $mydomain
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
home_mailbox = Maildir/
mynetworks = 127.0.0.0/8 192.168.10.0/24
# Uji kirim email via terminal (CLI)
echo "Halo, ini pesan uji coba mail server SMK" | mail -s "Uji Coba Mail Server" guru@smk.lan
