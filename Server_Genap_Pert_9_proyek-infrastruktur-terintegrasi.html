2 Blueprint Arsitektur Enterprise 3-Tier Terpadu

=============================================================================
                          TOPOLOGI 3-TIER ENTERPRISE
=============================================================================
  [ CLIENT LAPTOP / HP ] (IP DHCP: 192.168.10.100 - 200)
             │
             ▼ Query DNS: portal.smk.lan
  [ TIER 1: PRESENTATION & SECURITY LAYER ]
  ├─ DNS Master BIND9 (Port 53 UDP/TCP)
  ├─ Reverse Proxy Nginx + SSL TLS 1.3 (Port 443 HTTPS & Port 80 Redirect)
  └─ Firewall UFW (Default Deny Incoming Policy)
             │
             ▼ FastCGI / Proxy Pass (Internal Private Network)
  [ TIER 2: APPLICATION & COMPUTE LAYER ]
  ├─ Apache2 Web Server + PHP 8.1-FPM (Port 8080)
  ├─ SSH Hardening + Fail2ban (Port 2222 / Keypair Ed25519)
  └─ File Storage Sharing Samba & NFS (Port 445 / 2049)
             │
             ▼ SQL TCP Queries (Port 3306 - Terisolasi Hanya untuk Web Server)
  [ TIER 3: DATA & PERSISTENCE LAYER ]
  ├─ MariaDB Database Server (InnoDB Engine + ACID Compliance)
  ├─ RAID 5 Storage Array with Hot-Spare Rebuild (mdadm)
  └─ Backup Otomatis Harian (rsync + Crontab 3-2-1 Strategy)
=============================================================================

4 Laboratorium Troubleshooting: Deadlock Resolusi DNS Lokal

# KASUS: Web server tidak bisa menghubungi database menggunakan hostname (db.smk.lan) # Penyebab: /etc/resolv.conf di server masih mengarah ke 127.0.0.53 (systemd-resolved) bukan ke IP BIND9 DNS lokal (192.168.10.10). # Solusi: Edit file Netplan YAML pada baris 'nameservers: addresses: [192.168.10.10, 8.8.8.8]' lalu jalankan 'sudo netplan apply'.
