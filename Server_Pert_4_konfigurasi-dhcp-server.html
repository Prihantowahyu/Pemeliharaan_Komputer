Konfigurasi Layanan DHCP Server di Linux

Memahami cara kerja proses DORA, instalasi paket ISC-DHCP-Server, pengaturan Scope & Lease Time, Fixed MAC Reservation, dan pengujian client.

1 Cara Kerja Protokol DHCP (Proses 4 Tahap DORA)

DHCP (Dynamic Host Configuration Protocol) bertugas memberikan alamat IP, subnet mask, gateway, dan DNS secara otomatis kepada client.

1. Discover (Client)

Client menyiarkan (*broadcast*) pesan mencari DHCP server yang aktif.

2. Offer (Server)

Server menawarkan alokasi IP, subnet, gateway & durasi sewa (*lease*).

3. Request (Client)

Client menyetujui tawaran IP dan mengirim permintaan resmi peminjaman.

4. Acknowledge (Server)

Server mengonfirmasi peminjaman IP & mencatatnya ke database lease.

2 Instalasi & Konfigurasi Paket isc-dhcp-server

Edit file /etc/dhcp/dhcpd.conf untuk menentukan subnet IP range (Scope) yang akan dibagikan:

# 1. Instal paket isc-dhcp-server
sudo apt install -y isc-dhcp-server

# 2. Tentukan interface jaringan di /etc/default/isc-dhcp-server
INTERFACESv4="ens33"

# 3. Konfigurasi Scope di /etc/dhcp/dhcpd.conf
subnet 192.168.10.0 netmask 255.255.255.0 {
  range 192.168.10.50 192.168.10.150;
  option routers 192.168.10.1;
  option domain-name-servers 192.168.10.1, 8.8.8.8;
  default-lease-time 7200;       # 2 Jam
  max-lease-time 86400;          # 24 Jam
}

3 IP Reservation (Fixed MAC Binding)

Untuk perangkat khusus seperti Printer Jaringan atau Access Point, buat reservasi IP berdasarkan MAC Address:

host printer-lab-tkj {
  hardware ethernet 00:11:22:33:44:55;
  fixed-address 192.168.10.200;
}
# Restart layanan & cek status
sudo systemctl restart isc-dhcp-server
sudo systemctl status isc-dhcp-server
