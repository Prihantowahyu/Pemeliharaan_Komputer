Konfigurasi DHCP Server Linux (ISC-DHCP, Scope & MAC Binding)

Otomatisasi distribusi IP Address pada jaringan LAN menggunakan ISC-DHCP Server, pemahaman mendalam 4 tahap negosiasi DORA, manajemen Lease Time, dan reservasi IP statis berbasis MAC Address.

1 Cara Kerja Protokol DHCP (4 Tahap DORA)

1. DISCOVER (Broadcast)
Client mencari DHCP server: 0.0.0.0:68 -> 255.255.255.255:67.
2. OFFER (Unicast/Bcast)
Server menawarkan calon IP beserta subnet mask dan lease time.
3. REQUEST (Broadcast)
Client menyetujui tawaran IP dari DHCP server terpilih.
4. ACKNOWLEDGE (ACK)
Server meresmikan sewa IP dan mencatatnya ke database lease.

2 Konfigurasi ISC-DHCP Server (/etc/dhcp/dhcpd.conf)

# 1. Instalasi paket ISC DHCP Server
sudo apt install -y isc-dhcp-server

# 2. Tentukan interface yang mendengarkan request di /etc/default/isc-dhcp-server
INTERFACESv4="enp0s3"

# 3. Konfigurasi Subnet Scope & MAC Reservation di /etc/dhcp/dhcpd.conf
subnet 192.168.10.0 netmask 255.255.255.0 {
    range 192.168.10.50 192.168.10.150;
    option routers 192.168.10.254;
    option domain-name-servers 192.168.10.1, 8.8.8.8;
    option domain-name "smk.lan";
    default-lease-time 86400;      # 1 Hari
    max-lease-time 172800;          # 2 Hari
}

# Fixed MAC Reservation untuk Printer Lab / Server Khusus
host printer_lab {
    hardware ethernet 08:00:27:fa:4a:11;
    fixed-address 192.168.10.20;
}
# Restart layanan dan periksa status
sudo systemctl restart isc-dhcp-server
sudo systemctl status isc-dhcp-server
cat /var/lib/dhcp/dhcpd.leases
