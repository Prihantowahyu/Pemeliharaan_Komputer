2 Anatomi 4-Fase DORA & File Konfigurasi dhcpd.conf

FaseTipe PaketArah KomunikasiTujuan & Deskripsi Paket
1. DiscoverDHCPDISCOVER (Broadcast)Client → 255.255.255.255:67Client baru terhubung mencari apakah ada DHCP Server aktif di jaringan LAN.
2. OfferDHCPOFFER (Unicast/Broadcast)Server → ClientDHCP Server menawarkan kandidat IP Address, Subnet Mask, dan durasi sewa ke client.
3. RequestDHCPREQUEST (Broadcast)Client → ServerClient menyetujui tawaran IP tersebut dan meminta izin resmi pemakaian ke server.
4. AcknowledgmentDHCPACK (Unicast)Server → ClientServer mengonfirmasi legalitas IP, mengirim DNS/Gateway, dan mencatatnya ke dhcpd.leases.
# File: /etc/dhcp/dhcpd.conf — Konfigurasi Subnet & Reservation 
subnet 192.168.10.0 netmask 255.255.255.0 {
    range 192.168.10.100 192.168.10.200;       # Pool Dinamis untuk Client Umum
    option routers 192.168.10.1;               # Default Gateway
    option domain-name-servers 192.168.10.1, 8.8.8.8;
    option domain-name "smk.lan";
    default-lease-time 86400;                  # 24 Jam (detik)
    max-lease-time 172800;                     # 48 Jam
}

# Reservasi IP Khusus Printer Jaringan (Fixed IP Berbasis MAC)
host PRINTER_LAB_TKJ {
    hardware ethernet 00:1A:2B:3C:4D:5E;
    fixed-address 192.168.10.50;
}
