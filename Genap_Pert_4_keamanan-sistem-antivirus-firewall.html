Bagian 1

1. Konfigurasi Windows Defender Firewall with Advanced Security

Firewall bertindak sebagai gerbang filter pelindung yang memeriksa setiap paket data masuk (Inbound) dan keluar (Outbound).

Membuka Konsol Manajemen Firewall Tingkat Lanjut

Tekan Win + R → ketik wf.msc → tekan Enter untuk membuka konsol Windows Defender Firewall with Advanced Security.

Membuat Inbound Rule Baru untuk Blokir Port Berbahaya

Klik Inbound Rules → pilih New Rule... → pilih jenis Port → pilih protokol TCP → masukkan port spesifik (mis. 445, 139) → pilih aksi Block the connection → centang semua profil (Domain, Private, Public) → beri nama rule (mis. BLOKIR_SMB_MALWARE).

Verifikasi Status Proteksi Real-Time Antivirus

Buka Windows Security → Virus & threat protection → pastikan Real-time protection, Cloud-delivered protection, dan Tamper Protection berstatus ON.

Bagian 2

2. Cyber Hygiene & Mitigasi Serangan Social Engineering

Pertahanan terkuat dimulai dari kesadaran pengguna (User Awareness).

A. Proteksi Phishing

Jangan mengklik tautan mencurigakan atau mengunduh file lampiran dari pengirim tidak dikenal (mis. file berekstensi .exe, .vbs, atau .iso berkedok tagihan/invoice).

B. Nonaktifkan USB Auto-Run

Blokir fitur AutoPlay/AutoRun melalui Group Policy (gpedit.msc) agar virus USB shortcut tidak dapat mengeksekusi script secara otomatis saat flashdisk dicolokkan.

C. Manajemen Patch Update

Jalankan Windows Update rutin untuk menutup celah kerentanan (CVE) pada kernel sistem operasi dan browser.
