Struktur Pembelajaran

Alur Skenario Pembelajaran 9 Jam Pelajaran (9 JP)

Struktur komprehensif membagi 9 JP menjadi 5 fase terukur: Teori & Analisis, Demonstrasi & Observasi, Praktik Terbimbing, Kasus Industri, dan Evaluasi Laporan.

JP 1-2

Teori Ancaman Siber Modern & Arsitektur Keamanan Windows (90 Menit)

Jenis malware: virus, worm, trojan, ransomware, spyware, adware, rootkit. Cara kerja enkripsi ransomware (AES-256 + RSA). Arsitektur pertahanan berlapis Windows: DEP, ASLR, SmartScreen, Secure Boot, TPM 2.0, Windows Hello.

JP 3-4

Konfigurasi Windows Defender & Antivirus Lanjutan (90 Menit)

Aktivasi dan verifikasi komponen Windows Security (Real-time, Cloud-delivered, Tamper Protection). Exclusion paths yang aman. Scan on-demand vs scheduled. Pengaturan Controlled Folder Access (proteksi ransomware). Review quarantine. Perbandingan dengan antivirus pihak ketiga.

JP 5-6

Praktik Konfigurasi Windows Firewall with Advanced Security (90 Menit)

Membuka wf.msc. Pembuatan Inbound Rule untuk memblokir port berbahaya (445-SMB, 3389-RDP di Public). Pembuatan Outbound Rule untuk membatasi program tidak dikenal. Pengaturan Connection Security Rules. Ekspor/impor kebijakan firewall (.wfw file). Verifikasi dengan netstat.

JP 7-8

Manajemen Patch, Update & Group Policy Security (90 Menit)

Konfigurasi Windows Update Policy (gpedit.msc). Pemeriksaan update manual vs otomatis. Identifikasi CVE (Common Vulnerabilities and Exposures) berbahaya. Nonaktifkan fitur berbahaya: AutoRun USB (gpedit), RDP jika tidak diperlukan, SMBv1. Penerapan Local Security Policy (secpol.msc).

JP 9

Studi Kasus, Simulasi Insiden Keamanan & Evaluasi LKPD (45 Menit)

Analisis studi kasus: PC sekolah terinfeksi virus shortcut USB. Siswa melakukan langkah mitigasi: scan antivirus, pemeriksaan startup (msconfig), penghapusan entri registry malware, dan pembuatan laporan insiden keamanan.

Bagian A · Ancaman Siber

A. Peta Ancaman Siber Modern pada Sistem Komputer

Memahami anatomi serangan adalah langkah pertama pertahanan yang efektif. Seorang teknisi TKJ harus mampu mengenali dan menangani insiden siber di lingkungan sekolah/kantor.

Ransomware (Ancaman #1)

Malware paling destruktif. Mengenkripsi seluruh file dokumen, foto, dan database menggunakan algoritma AES-256 + RSA-2048. Korban diminta membayar tebusan (ransom) dalam cryptocurrency untuk mendapat kunci dekripsi.

  • Penyebaran: Email phishing, exploit SMBv1 (WannaCry), RDP brute force
  • Pencegahan: Backup 3-2-1, patch OS, Controlled Folder Access aktif

Virus Shortcut USB

Jenis malware yang paling umum di lingkungan sekolah. Virus menyembunyikan semua folder asli dan menggantinya dengan shortcut .lnk yang menjalankan script berbahaya saat diklik. Menyebar via flashdisk.

  • Pencegahan: Nonaktifkan AutoPlay/AutoRun via Group Policy
  • Pemulihan: attrib -h -r -s /s /d F:\ di CMD untuk mengembalikan folder tersembunyi

Phishing & Social Engineering

Serangan yang memanipulasi psikologi manusia, bukan eksploitasi teknis. Email/pesan palsu yang menyamar sebagai bank, instansi pemerintah, atau perusahaan terpercaya untuk mencuri kredensial login.

  • Ciri-ciri: Domain pengirim tidak resmi, urgensi palsu, link mencurigakan
  • Pencegahan: Verifikasi manual, jangan klik link sembarangan
Bagian B · Konfigurasi Firewall

B. Panduan Lengkap Konfigurasi Windows Firewall with Advanced Security

Windows Firewall with Advanced Security (wf.msc) menyediakan kontrol granular atas trafik jaringan yang jauh lebih detail dibandingkan Control Panel biasa.

Membuka Konsol Firewall Lanjutan

Tekan Win + R → ketik wf.msc → Enter. Panel kiri menampilkan: Inbound Rules, Outbound Rules, Connection Security Rules, dan Monitoring. Profil aktif (Domain/Private/Public) ditampilkan di panel tengah.

Membuat Inbound Rule: Blokir Port SMB 445

Klik Inbound Rules → New Rule. Pilih Type: Port. Protokol: TCP. Specific local ports: 445. Action: Block the connection. Profile: centang Domain, Private, dan Public. Name: BLOKIR-SMB-445-AntiRansomware. Klik Finish. Rule aktif langsung tanpa restart.

Membuat Inbound Rule: Izinkan Program Spesifik

Untuk mengizinkan program spesifik (bukan berdasarkan port), pilih Type: Program. Browse ke lokasi executable (%ProgramFiles%\aplikasi.exe). Action: Allow the connection. Ini lebih aman daripada membuka port secara permanen.

Verifikasi Aturan Firewall dengan Netstat

Buka CMD → jalankan netstat -an | findstr LISTEN untuk melihat port yang sedang mendengarkan (listening). Pastikan port berbahaya (445, 23, 3389 jika tidak digunakan) tidak muncul dalam status LISTENING.

Ekspor Kebijakan Firewall sebagai File Cadangan

Di konsol wf.msc, klik kanan Windows Defender Firewall with Advanced Security di panel kiri → pilih Export Policy. Simpan file .wfw. File ini bisa diimpor ke PC lain untuk menerapkan kebijakan yang sama secara massal (berguna untuk lab sekolah).

Bagian C · Patch Management

C. Manajemen Patch Keamanan & Hardening OS Windows

Patch update bukan sekadar pembaruan fitur — setiap update keamanan menutup celah (CVE) yang bisa dieksploitasi peretas. PC yang tidak diupdate adalah target empuk.

Langkah Hardening Windows via Group Policy (gpedit.msc)

  • Nonaktifkan AutoRun USB: Computer Configuration → Administrative Templates → Windows Components → AutoPlay Policies → Disable Autoplay: All Drives
  • Nonaktifkan SMBv1: Jalankan PowerShell Admin: Set-SmbServerConfiguration -EnableSMB1Protocol $false
  • Batasi akses RDP: System Properties → Remote → hanya izinkan pengguna tertentu
  • Aktifkan Audit Log: Local Security Policy → Audit Policy → aktifkan Audit logon events

Controlled Folder Access (Proteksi Ransomware)

Fitur eksklusif Windows 10/11 yang mencegah program tidak dikenal mengakses atau memodifikasi file di folder yang dilindungi (Documents, Desktop, Pictures, dll).

Cara aktifkan: Windows Security → Virus & threat protection → Manage ransomware protection → Controlled folder access: ON

Tambahkan folder penting sekolah ke daftar protected folders untuk perlindungan ekstra.

✓ Checklist Minimum Security Hardening untuk PC Lab Sekolah:
☐ Windows Defender Real-time Protection: ON | ☐ Firewall aktif untuk semua profil | ☐ AutoPlay/AutoRun: Dinonaktifkan via GPO | ☐ SMBv1: Dinonaktifkan | ☐ Windows Update: Otomatis aktif | ☐ Controlled Folder Access: ON | ☐ User Account Control (UAC): Level Maksimal
