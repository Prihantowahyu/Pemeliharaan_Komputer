METODE PEMULIHAN: System Restore Point
1. Tekan Win+R → ketik rstrui → Enter. 2. Pilih "Choose a different restore point". 3. Pilih titik pemulihan sebelum masalah terjadi. 4. Klik Next → Finish → konfirmasi. 5. Bagian A · Strategi Backup

A. Strategi Backup 3-2-1: Standar Industri Zero Data Loss

Kehilangan data adalah salah satu insiden paling merugikan di lingkungan pendidikan dan bisnis. Strategi 3-2-1 adalah standar minimum yang digunakan oleh para profesional IT untuk memastikan data selalu dapat dipulihkan.

3 — Tiga Salinan Data

Miliki minimal 3 salinan dari setiap data penting: 1 data asli (primary) + 2 salinan backup. Mengapa 3? Karena dua salinan masih rentan — jika dua terjadi kerusakan bersamaan (mis. banjir mengenai PC + external drive di ruangan sama), data masih aman di salinan ketiga.

2 — Dua Jenis Media Berbeda

Simpan salinan pada 2 jenis media fisik berbeda, misalnya: Internal SSD (media 1) + External HDD USB (media 2). Mengapa berbeda? Karena satu jenis media memiliki mode kegagalan yang sama — semua SSD bisa tiba-tiba gagal bersamaan saat usia pakai habis.

1 — Satu Salinan Off-Site / Cloud

Simpan 1 salinan di lokasi terpisah atau cloud storage (Google Drive, OneDrive, IDriveE2). Ini melindungi dari bencana fisik seperti kebakaran atau banjir yang bisa menghancurkan semua perangkat di satu lokasi sekaligus.

RPO & RTO: Recovery Point Objective (RPO) = berapa lama data yang boleh hilang (misal: backup harian = RPO 24 jam). Recovery Time Objective (RTO) = berapa lama sistem boleh down sebelum pulih. Semakin kecil RPO dan RTO, semakin kritis sistem tersebut dan semakin mahal solusi backup yang diperlukan.
Bagian B · Media Instalasi

B. Membuat Bootable USB Windows dengan Rufus

Rufus adalah software gratis dan portabel terpopuler untuk membuat USB bootable Windows 10/11 dan distribusi Linux.

Download ISO Windows & Persiapan USB

Download ISO Windows resmi dari microsoft.com/software-download/windows11. Siapkan USB minimal 8 GB. PERHATIAN: Semua data di USB akan dihapus. Backup isi USB terlebih dahulu jika ada data penting.

Konfigurasi Rufus yang Tepat

Device: pilih USB drive. Boot selection: pilih ISO. Partition scheme: GPT (untuk PC modern UEFI). Target system: UEFI (non CSM). File system: NTFS atau FAT32 (jika ukuran ISO < 4GB). Cluster size: default. Klik START. Pilih mode Standard Windows Installation untuk instalasi normal.

Mengatur Boot Priority di BIOS/UEFI

Restart PC → tekan Del/F2/F12 saat logo muncul → masuk BIOS/UEFI. Cari menu Boot Order / Boot Priority. Pindahkan USB Drive ke urutan pertama. Simpan (F10) dan restart. PC akan boot dari USB. Jika tidak berhasil, cek apakah Secure Boot perlu dinonaktifkan sementara untuk USB non-Microsoft.

Proses Instalasi: Custom Advanced (Clean Install)

Pilih "Custom: Install Windows only (advanced)" bukan Upgrade. Hapus semua partisi lama dengan tombol Delete hingga hanya ada "Unallocated Space". Klik New untuk membuat partisi baru. Windows akan otomatis membuat partisi EFI, MSR, dan partisi sistem. Klik Next untuk memulai instalasi.

Bagian C · System Restore

C. Membuat & Mengelola System Restore Point

System Restore adalah "mesin waktu" Windows yang menyimpan snapshot registry, driver, dan file sistem — bukan file pribadi — pada titik waktu tertentu.

Mengaktifkan System Protection

Buka System Properties (sysdm.cpl) → tab System Protection. Pilih drive C: → klik Configure. Pilih "Turn on system protection". Atur kapasitas disk: minimal 5-10% (sekitar 5-15 GB). Klik OK. Tanpa ini, Restore Point tidak bisa dibuat.

Membuat Restore Point Manual Sebelum Perubahan Besar

Setiap kali akan melakukan perubahan besar (instal driver baru, update besar, atau eksperimen registry), buat Restore Point manual: tab System Protection → klik Create... → beri deskripsi (misal: SEBELUM-INSTAL-DRIVER-GPU-560) → klik Create. Selesai dalam hitungan detik.

Rollback via System Restore saat Masalah Terjadi

Jika Windows mulai bermasalah setelah perubahan: Win + R → rstrui → pilih titik pemulihan yang dibuat sebelumnya → Next → Finish. Sistem restart dan memulihkan diri dalam 15-20 menit. File di Documents, Desktop, dll tidak terpengaruh — hanya konfigurasi sistem yang di-rollback.
