Bagian 1

1. Strategi Backup 3-2-1 Sebelum Instalasi Ulang

Aturan baku industri untuk menjamin nol kehilangan data (Zero Data Loss).

3 Salinan Data

Miliki minimal 3 salinan data penting: 1 data utama di PC dan 2 salinan cadangan backup.

2 Media Berbeda

Simpan cadangan data pada 2 jenis media penyimpanan fisik yang berbeda (mis. Internal SSD + External HDD USB / NAS).

1 Salinan Off-site

Simpan 1 salinan di lokasi fisik berbeda atau cloud storage (Google Drive, OneDrive) untuk antisipasi bencana fisik.

Bagian 2

2. Membuat & Menggunakan System Restore Point

Fitur snapshot otomatis yang mencatat konfigurasi registry, driver, dan file sistem Windows.

Mengaktifkan System Protection

Buka System Properties (ketik sysdm.cpl) → tab System Protection → pilih Drive C: (System) → klik Configure → pilih Turn on system protection → alokasikan ruang disk minimal 5-10%.

Membuat Manual Restore Point

Klik tombol Create... → masukkan deskripsi (mis. SEBELUM_UPDATE_DRIVER_VGA) → klik Create. Windows akan membuat snapshot registry dalam beberapa detik.

Rollback Sistem Melalui Windows Recovery Environment (WinRE)

Jika Windows mengalami crash/BSOD, masuk ke mode Advanced Startup → Troubleshoot → Advanced options → System Restore → pilih titik snapshot yang diinginkan → sistem akan otomatis pulih ke kondisi stabil.
