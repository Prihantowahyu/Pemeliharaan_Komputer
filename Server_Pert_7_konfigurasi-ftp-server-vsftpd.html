Konfigurasi FTP Server (vsftpd & Chroot Jail)

Mengatur layanan transfer file berkecepatan tinggi menggunakan VSFTPD, isolasi keamanan Chroot Jail user, dan pengujian upload/download dengan client FileZilla.

1 Cara Kerja FTP (Port 21 Command & Port 20 Data)

FTP (File Transfer Protocol) menggunakan 2 saluran koneksi terpisah:

  • Port 21 (Command Channel): Mengirim perintah navigasi, otentikasi login, dan kontrol sesi.
  • Port 20 (Data Channel): Mentransfer aliran data file (upload/download file besar).

2 Konfigurasi Aman /etc/vsftpd.conf

# 1. Instal vsftpd
sudo apt install -y vsftpd

# 2. Pengaturan keamanan di /etc/vsftpd.conf
anonymous_enable=NO
local_enable=YES
write_enable=YES
chroot_local_user=YES
allow_writeable_chroot=YES
local_umask=022
pasv_min_port=40000
pasv_max_port=40100
# Restart layanan vsftpd
sudo systemctl restart vsftpd
sudo systemctl status vsftpd
