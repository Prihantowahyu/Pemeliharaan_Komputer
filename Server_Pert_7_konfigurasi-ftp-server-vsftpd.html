Konfigurasi FTP Server vsftpd (Chroot Jail & Upload/Download via FileZilla)

1 Arsitektur Port & Mode Koneksi FTP

Mode KoneksiPort ControlPort DataKeterangan NAT/Firewall
Active Mode21 (Client→Server)20 (Server→Client)Bermasalah di balik NAT karena server memulai koneksi data ke client
Passive Mode (PASV)21 (Client→Server)Port Dinamis (Client→Server)Aman untuk NAT; client yang memulai semua koneksi

2 Konfigurasi File /etc/vsftpd.conf

# /etc/vsftpd.conf — Konfigurasi vsftpd enterprise listen=YES listen_ipv6=NO anonymous_enable=NO local_enable=YES write_enable=YES local_umask=022 dirmessage_enable=YES use_localtime=YES xferlog_enable=YES connect_from_port_20=YES # Chroot Jail: Kurung user agar tidak bisa keluar dari home dir chroot_local_user=YES allow_writeable_chroot=YES # Passive Mode untuk firewall/NAT pasv_enable=YES pasv_min_port=40000 pasv_max_port=50000 pasv_address=192.168.10.1 # Batas Upload File local_max_rate=1048576
# Buat user FTP khusus untuk siswa sudo adduser siswa_ftp sudo mkdir -p /home/siswa_ftp/upload sudo chown nobody:nogroup /home/siswa_ftp sudo chmod a-w /home/siswa_ftp sudo chown siswa_ftp:siswa_ftp /home/siswa_ftp/upload sudo systemctl restart vsftpd
