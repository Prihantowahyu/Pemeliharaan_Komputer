📖 Materi: Apa itu FTP dan Mengapa Masih Digunakan?

FTP (File Transfer Protocol) adalah protokol layer aplikasi (RFC 959) yang digunakan untuk mentransfer file antara FTP Client dan FTP Server melalui jaringan TCP/IP. Distandarkan sejak 1985, FTP masih digunakan karena:
  • ✅ Mendukung upload/download file berukuran besar (multi-GB)
  • ✅ Resume transfer yang terputus
  • ✅ Manajemen user dan direktori yang mudah
  • ✅ Terintegrasi di hampir semua sistem operasi dan aplikasi

Teori Mendalam: Active Mode vs Passive Mode FTP
⏱ 08.30 – 09.30 · 60 Menit
▼

📖 Cara Kerja FTP: 2 Saluran Komunikasi

FTP unik karena menggunakan 2 koneksi TCP terpisah: Control Channel (untuk perintah) dan Data Channel (untuk transfer file). Perbedaan Active vs Passive terletak pada SIAPA yang membuka Data Channel.
🔴 Active Mode (PORT)
  • Client → Server: koneksi ke Port 21 (Control)
  • Client memberi tahu nomor portnya sendiri via perintah PORT
  • Server → Client: Server aktif membuka koneksi Data dari port 20 ke port client
  • Masalah: NAT/Firewall client memblokir koneksi masuk dari server!
  • Port Data: Selalu dari port 20 di server
🟢 Passive Mode (PASV) — Direkomendasikan
  • Client → Server: koneksi ke Port 21 (Control)
  • Client mengirim perintah PASV ke server
  • Server membalas dengan IP dan port acak (misal: 50000-60000)
  • Client aktif membuka koneksi Data ke port acak server tersebut
  • Keuntungan: Client membuka koneksi ke luar, melewati NAT dengan mudah!
# Ilustrasi Active Mode (SERVER membuka data connection ke CLIENT)
CLIENT (random port: 1234) ──→ SERVER port 21  [Control: LOGIN, LIST, RETR]
SERVER port 20 ──────────────→ CLIENT port 1234 [Data: transfer file]
❌ Masalah: Firewall CLIENT memblokir koneksi MASUK dari server!

# Ilustrasi Passive Mode (CLIENT membuka data connection ke SERVER)
CLIENT (random port: 1234) ──→ SERVER port 21  [Control: LOGIN]
CLIENT mengrim PASV ──────────→ SERVER membalas: "Hubungi saya di port 50001"
CLIENT (random port: 1235) ──→ SERVER port 50001 [Data: transfer file]
✅ Firewall CLIENT mengizinkan koneksi KELUAR ke server!

📋 Port FTP yang Harus Diizinkan di Firewall

Konfigurasi vsftpd: Chroot Jail & Keamanan
⏱ 09.30 – 10.30 · 60 Menit
▼

📄 File Konfigurasi /etc/vsftpd.conf Lengkap dengan Penjelasan

# /etc/vsftpd.conf — Very Secure FTP Daemon Configuration

listen=YES                   # vsftpd berjalan mandiri (standalone)
listen_ipv6=NO              # Hanya gunakan IPv4
anonymous_enable=NO         # ❌ LARANG login anonymous! (keamanan)
local_enable=YES            # ✅ Izinkan user sistem Linux login
write_enable=YES            # ✅ Izinkan upload file
local_umask=022             # Permission file yang diupload: 755 (dir), 644 (file)

# === CHROOT JAIL (Isolasi User ke Direktori Home) ===
chroot_local_user=YES       # ✅ Kunci user di dalam home direktorinya saja
allow_writeable_chroot=YES  # Diperlukan jika home dir bisa ditulis
chroot_list_enable=NO       # Tidak pakai whitelist chroot

# === PASSIVE MODE CONFIGURATION ===
pasv_enable=YES             # ✅ Aktifkan Passive Mode
pasv_min_port=50000         # Port minimum untuk data passive
pasv_max_port=50100         # Port maksimum untuk data passive
pasv_address=192.168.10.10  # IP publik/lokal server (untuk NAT)

# === USER LIST WHITELIST ===
userlist_enable=YES         # Aktifkan user list
userlist_file=/etc/vsftpd.userlist
userlist_deny=NO            # NO = userlist adalah WHITELIST (hanya user terdaftar yang boleh)

# === KEAMANAN ===
tcp_wrappers=YES            # Aktifkan kontrol akses TCP Wrappers
ftpd_banner=Welcome to SMK FTP Server.
xferlog_enable=YES          # ✅ Catat semua transfer file ke log
xferlog_file=/var/log/vsftpd.log

🔐 Konsep Chroot Jail — Penting Dipahami!

Chroot Jail adalah teknik keamanan yang "memenjarakan" user FTP di dalam direktori home mereka sendiri. Jika user guru_tkj login via FTP, mereka hanya bisa melihat dan mengakses isi /home/guru_tkj/ — tidak bisa naik ke /var/www/ atau /etc/! 
# Tanpa Chroot Jail (BERBAHAYA!):
ftpuser login → bisa akses /   → bisa lihat /etc/passwd, /var/www, dll!

# Dengan Chroot Jail (AMAN!):
ftpuser login → hanya bisa akses /home/ftpuser/   → tidak bisa kemana-mana

# Syarat Chroot Jail bekerja — direktori home TIDAK boleh dimiliki si user:
sudo chown root:root /home/guru_tkj   # Owner: root
sudo chmod 755 /home/guru_tkj         # Hanya bisa baca, tidak bisa tulis ke folder home
sudo mkdir /home/guru_tkj/upload      # Buat subdirektori untuk upload
sudo chown guru_tkj:guru_tkj /home/guru_tkj/upload  # Subfolder boleh dimiliki user

Praktikum Mandiri — Setup FTP Server Enterprise dengan Chroot
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
🎯 Target: FTP Server berjalan, user guru_tkj bisa login, upload, dan download via FileZilla, terisolasi dalam Chroot Jail.
1
Install vsftpd:
sudo apt update && sudo apt install -y vsftpd
sudo systemctl enable --now vsftpd
sudo systemctl status vsftpd  # Harus: active (running)
2
Buat user FTP khusus (jangan gunakan root!):
sudo useradd -m -s /bin/bash guru_tkj
sudo passwd guru_tkj
# Masukkan password yang kuat
3
Setup direktori dengan Chroot yang benar:
# Direktori home TIDAK boleh dimiliki si user (syarat chroot)
sudo chown root:root /home/guru_tkj
sudo chmod 755 /home/guru_tkj

# Buat subdirektori upload yang boleh ditulis
sudo mkdir /home/guru_tkj/files
sudo chown guru_tkj:guru_tkj /home/guru_tkj/files
sudo chmod 755 /home/guru_tkj/files
4
Backup dan edit konfigurasi vsftpd.conf:
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.backup
sudo nano /etc/vsftpd.conf
# Isi dengan konfigurasi dari Fase 3 di atas
5
Buat file whitelist user:
echo "guru_tkj" | sudo tee /etc/vsftpd.userlist
# Setiap baris = 1 nama user yang diizinkan login FTP
6
Izinkan port FTP di firewall:
sudo ufw allow 21/tcp
sudo ufw allow 50000:50100/tcp  # Port passive mode
sudo ufw status
7
Restart vsftpd dan uji dari server:
sudo systemctl restart vsftpd
ftp 127.0.0.1
# Masuk dengan: username guru_tkj, password yang dibuat tadi
# Perintah FTP: ls, pwd, get [file], put [file], bye
8
Uji dengan FileZilla dari laptop siswa:
  • Buka FileZilla → masuk menu File → Site Manager
  • Protocol: FTP, Host: 192.168.10.10, Port: 21
  • Encryption: Use plain FTP (untuk lab, production pakai FTPS)
  • Logon type: Normal, User: guru_tkj, Password: [sesuai]
  • Klik Connect
9
Uji upload dan download file:
  • Di FileZilla: drag file dari laptop ke panel kanan (server) → upload
  • Cek file muncul di server: ls /home/guru_tkj/files/
  • Coba akses direktori di atas home (cd /) → harus muncul folder home sebagai root (Chroot berhasil!)
10
Pantau log transfer:
sudo tail -f /var/log/vsftpd.log
# Setiap upload/download tercatat dengan timestamp, user, dan nama file
✅ Kriteria Berhasil: Login FileZilla sukses, upload file berhasil, Chroot berfungsi (tidak bisa naik ke direktori /), dan log transfer tercatat.
