Konfigurasi File Transfer Protocol (FTP) Server dengan vsftpd & Chroot Jail

Panduan deployment layanan transfer data cepat dan aman: Membedah perbedaan mode FTP Active (Port 20/21) vs Passive (Rentang Port Pasif), instalasi vsftpd (Very Secure FTP Daemon), isolasi keamanan Chroot Jail (mengunci user di folder home agar tidak bisa menelusuri direktori root server), pembatasan user via userlist, serta pengujian transfer client FileZilla.

2 Konfigurasi Hardening /etc/vsftpd.conf

# File: /etc/vsftpd.conf — Standar Keamanan Enterprise 
listen=YES
listen_ipv6=NO
anonymous_enable=NO                  # Blokir login anonim tanpa password
local_enable=YES                      # Izinkan login user lokal Linux
write_enable=YES                      # Izinkan upload & hapus file
local_umask=022                       # Izin file upload default 644 / folder 755

# Isolasi Keamanan Chroot Jail
chroot_local_user=YES
allow_writeable_chroot=YES            # Mencegah error 500 OOPS writable root

# Rentang Port Mode Pasif untuk Menembus NAT/Firewall
pasv_enable=YES
pasv_min_port=10000
pasv_max_port=10100

# Pembatasan Userlist Whitelist
userlist_enable=YES
userlist_file=/etc/vsftpd.userlist
userlist_deny=NO                      # Hanya user di file ini yang boleh login!

# KASUS: 500 OOPS: vsftpd: refusing to run with writable root inside chroot() # Penyebab: Sejak vsftpd versi 2.3.5+, daemon menolak mengurung user jika folder home utama memiliki izin write (keamanan). # Solusi Terbaik: Tambahkan opsi berikut di /etc/vsftpd.conf: allow_writeable_chroot=YES sudo systemctl restart vsftpd
