1 Pengertian & Tipe Arsitektur Server

Server adalah sistem komputer khusus yang memiliki spesifikasi tinggi, keandalan tinggi (24/7 uptime), dan bertugas melayani permintaan (request) dari komputer client dalam suatu jaringan lokal maupun internet.

Hardware Dedicated

1. Server Fisik (Bare Metal)

Unit server fisik berbentuk Rackmount / Tower / Blade yang berjalan langsung di atas hardware tanpa lapisan virtualisasi.

  • Kelebihan: Performa maksimal, latency paling rendah, akses penuh ke hardware.
  • Kekurangan: Biaya awal mahal, sulit di-scale cepat, utilisasi CPU sering mubazir.
Hypervisor / VM

2. Server Virtual (Virtual Machine)

Server logis yang berjalan di atas Hypervisor (Proxmox, VMware ESXi, KVM) membagi 1 server fisik menjadi banyak VM mandiri.

  • Kelebihan: Efisiensi biaya tinggi, snapshot & backup mudah, isolasi aman.
  • Kekurangan: Memiliki overhead performa kecil dari layer hypervisor.
Cloud Computing

3. Cloud Server (IaaS / PaaS)

Infrastruktur komputasi server elastis yang disediakan oleh cloud provider (AWS, Google Cloud, Azure, DigitalOcean).

  • Kelebihan: Bayar sesuai pemakaian (Pay-as-you-go), uptime tinggi, deploy instan.
  • Kekurangan: Bergantung koneksi internet, biaya jangka panjang bisa tinggi jika tidak dikelola.

3 Standar Keandalan Tier Data Center (Uptime Institute)

Standar Tier mengukur seberapa andal (*resilient*) sebuah data center dalam menjaga server tetap beroperasi tanpa henti:

Tier Level Ketersediaan (Uptime) Maks Downtime / Tahun Redundansi Komponen Karakteristik Utama
Tier 1 (Basic) 99.671% ~28.8 Jam N (Non-redundant) Jalur tunggal listrik & pendingin, mati saat maintenance.
Tier 2 (Redundant) 99.741% ~22.0 Jam N + 1 (Sebagian) Memiliki genset cadangan & UPS tambahan.
Tier 3 (Concurrently Maintainable) 99.982% ~1.6 Jam N + 1 (Penuh) Bisa maintenance tanpa mematikan server sama sekali.
Tier 4 (Fault Tolerant) 99.995% ~26.3 Menit 2(N + 1) (Dual Active) Tahan terhadap segala kegagalan komponen fisik & bencana.
