1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Apersepsi Masalah Industri 08.00 - 08.30 (30 Menit)

Guru memutar video studi kasus: "Dampak Downtime 1 Jam Server E-Commerce Terhadap Kerugian Milyaran Rupiah". Siswa mengerjakan Pre-Test mandiri 5 soal via smartphone untuk memetakan pemahaman awal mengenai server vs PC desktop biasa. Guru menyampaikan tujuan pembelajaran dan pembagian 6 kelompok kerja lab.

Fase 2: Eksplorasi Konsep & Arsitektur Hardware Server 08.30 - 09.30 (60 Menit)

Pemaparan interaktif mengenai form factor server (Tower, Rackmount 1U-4U, Blade Chassis), komponen ECC Registered RAM yang tahan bit-flip error, prosesor multi-core Intel Xeon / AMD EPYC, Hot-Swappable Redundant PSU, serta backplane SAS/NVMe. Siswa mengamati display fisik server riil/miniatur lab.

Fase 3: Standarisasi Datacenter & Tata Kelola Suhu/Daya 09.30 - 10.30 (60 Menit)

Bedah standar Tier 1 hingga Tier 4 ANSI/TIA-942 & Uptime Institute. Eksplorasi sistem pendinginan Hot/Cold Aisle containment, raised floor, Automatic Transfer Switch (ATS) genset diesel, UPS online double-conversion, dan manajemen jarak jauh OOB (IPMI / iDRAC / iLO).

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Peregangan siswa dan persiapan keselamatan kerja (ESD bracelet & sepatu karet).

Fase 4: Praktikum Mandiri — Simulasi Rakit Server & Audit Server Room 10.45 - 13.15 (150 Menit)

Siswa bekerja dalam kelompok mengerjakan Job Sheet 1: (1) Menghitung kebutuhan unit rak (U-space) untuk 10 server sekolah, (2) Merancang skema kelistrikan dual-feed PDU (Power Distribution Unit), (3) Mengonfigurasi antarmuka IPMI/BMC virtual via IP statis, dan (4) Menyusun dokumen audit suhu PUE (Power Usage Effectiveness).

Fase 5: Skenario Troubleshooting & Simulasi Kegagalan Daya 13.15 - 14.15 (60 Menit)

Guru menginjeksikan 2 skenario gangguan acak: PSU primer putus dan kegagalan sensor pendingin. Kelompok siswa melakukan diagnosa sistematis menggunakan log BMC/IPMI dan menerapkan prosedur tanggap darurat switch-over.

Fase 6: Evaluasi CBT, Presentasi & Refleksi Pembelajaran 14.15 - 15.00 (45 Menit)

Siswa mengerjakan evaluasi CBT Anti-Cheat 30 menit. Perwakilan kelompok mempresentasikan hasil audit rak server. Guru memberikan feedback dan pengantar untuk modul instalasi Linux Server di pertemuan berikutnya.

2 Materi Teknis: Hardware Server vs PC Desktop

KarakteristikServer Enterprise (Misal: Dell PowerEdge R750)Komputer Desktop Biasa (PC Client)
Duty Cycle & Uptime24/7/365 Non-Stop (MTBF > 100.000 Jam)8–12 Jam per hari (Restart rutin)
Tipe Memori (RAM)ECC Registered (RDIMM/LRDIMM) — Mampu mendeteksi dan mengoreksi error bit memori secara otomatis (Parity correction)Non-ECC Unbuffered (Mudah crash/BSOD jika terjadi bit-flip kosmik)
Sistem Catu DayaDual / Quad Redundant Hot-Plug PSU (1+1 atau 2+2) dengan sumber listrik PDU terpisahSingle ATX Power Supply (Mati jika kabel terlepas/rusak)
Penyimpanan (Storage)Enterprise SAS 12Gbps / NVMe U.2 Hot-Swap dengan hardware RAID Controller + BBU (Battery Backup Unit)Consumer SATA 6Gbps / M.2 PCIe tanpa proteksi power-loss
Manajemen Jarak JauhOut-of-Band Management (OOB) dedicated NIC (IPMI 2.0 / iDRAC9 / iLO 5) — Bisa reboot, install ISO, cek sensor saat OS matiIn-Band Software (AnyDesk/TeamViewer — Hanya bisa saat OS hidup)

💡 Mengapa Server Menggunakan Satuan Rack Unit (1U = 1.75 Inci)?

Standar EIA-310 menetapkan lebar rak server adalah 19 inci dan tinggi kelipatan 1U (44.45 mm atau 1.75 inci). Server 1U dirancang tipis dan padat untuk web/compute node, sedangkan server 2U/4U memiliki ruang pendingin lebih besar dan menampung puluhan hard drive 3.5" untuk database dan storage cluster.

4 Lembar Kerja Peserta Didik (Job Sheet Lab Hands-On 9 JP)

Tugas Proyek Lab: Perencanaan Rak Server 42U untuk Data Center Sekolah

Skenario Kasus: Sekolah Anda menerima hibah perangkat jaringan dan server baru: 1x Core Switch 1U, 2x Patch Panel 24-port 1U, 1x Firewall Router 1U, 4x Web/App Server 2U, 2x Database Server 2U, 1x Storage NAS 4U, dan 2x Rackmount UPS 3U. Setiap kelompok wajib menyusun layout penempatan rak dan perhitungan daya total.

Nomor LangkahAktivitas Praktikum yang DikerjakanTarget Output & Kriteria Keberhasilan
Langkah 1Kalkulasi Total U-Space yang dibutuhkan: (1+2+1) + (4×2) + (2×2) + 4 + (2×3) = 4 + 8 + 4 + 4 + 6 = 26U dari rak 42U.Siswa menyisakan 16U (38%) untuk sirkulasi udara & ekspansi masa depan.
Langkah 2Pemberian Layout Rak: Tempatkan UPS di posisi paling bawah (U01-U06) demi stabilitas titik berat rak (Center of Gravity).Diagram posisi rak vertikal digambar rapi pada kertas kerja/software draw.io.
Langkah 3Pengaturan Sirkulasi Udara: Pasang Blanking Panel di ruang 16U yang kosong.Mencegah udara panas dari belakang rak (Hot Aisle) memutar balik ke intake depan.
Langkah 4Koneksi Out-of-Band (OOB) IPMI: Hubungkan port BMC dedicated ke Management Switch terpisah (VLAN 99).Akses Web GUI IPMI server via IP 192.168.99.10 berhasil terbuka di browser siswa.
