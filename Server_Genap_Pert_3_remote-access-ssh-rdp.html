Pendahuluan — Mengapa Port 22 SSH Standar Diserang Ribuan Botnet Setiap Hari?
⏱ 08.00 – 08.30 · 30 Menit
▼

Botnet otomatis di internet melakukan pemindaian massal ke Port 22 untuk menebak username 'root' dan password lemah seperti '123456' atau 'admin' (Brute-Force Dictionary Attack). Trik pertama mengamankan server adalah memindahkan port dan mematikan autentikasi password!

2
Kriptografi Asimetris SSH: Private Key (Klien) vs Public Key (Server)
⏱ 08.30 – 09.30 · 60 Menit
▼ 
[ LAPTOP SISWA (CLIENT) ]                                [ SERVER LINUX ]
├─ Private Key: id_ed25519 (RAHASIA DI LAPTOP!)            └─ ~/.ssh/authorized_keys
└─ Public Key: id_ed25519.pub ──(ssh-copy-id)───────────────> (Disimpan di Server)

Saat Login:
1. Server membuat teka-teki acak (Challenge) dienkripsi dengan Public Key
2. Laptop Client memecahkan teka-teki menggunakan Private Key miliknya
3. Login Berhasil Seketika TANPA Mengirimkan Password Melalui Jaringan!
3
Bedah File Konfigurasi /etc/ssh/sshd_config
⏱ 09.30 – 10.30 · 60 Menit
▼ 
# /etc/ssh/sshd_config — Standar Hardening Enterprise
Port 2222                      # Pindahkan dari port default 22
PermitRootLogin no             # Larang keras login langsung user root
PubkeyAuthentication yes       # Wajibkan kunci enkripsi
PasswordAuthentication no      # Matikan login password sepenuhnya!
MaxAuthTries 3                 # Putus koneksi jika salah 3 kali

4
Praktikum Mandiri — Key Generation & Fail2ban Jail Setup (150 Menit)
⏱ 10.45 – 13.15 · 150 Menit (3,5 JP)
▼
1
Di Laptop Client: Generate kunci modern Ed25519:
ssh-keygen -t ed25519 -C "admin_smk@laptop"
2
Kirim Public Key ke Server:
ssh-copy-id -p 2222 wahyu@192.168.10.10
3
Di Server: Install & Konfigurasi Fail2ban:
sudo apt install -y fail2ban
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo nano /etc/fail2ban/jail.local
# Set: bantime = 1h, findtime = 10m, maxretry = 3
sudo systemctl restart fail2ban
4
Login instan tanpa password via kunci:
ssh -p 2222 wahyu@192.168.10.10

Simulasi Serangan Brute-Force & Verifikasi Auto-Ban IPTables
⏱ 13.15 – 14.15 · 60 Menit
▼

Siswa mencoba sengaja salah memasukkan password 3 kali dari laptop teman, lalu memeriksa status pemblokiran IP:

sudo fail2ban-client status sshd
# Melepas blokir IP (Unban):
sudo fail2ban-client set sshd unbanip [IP_Laptop_Teman]
