1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Ancaman Botnet Brute-Force Port 22 08.00 - 08.30 (30 Menit)

Apersepsi: Guru menampilkan log serangan live di /var/log/auth.log server publik yang dibombardir 5.000 percobaan login ilegal per menit. Memahami mengapa autentikasi password biasa dilarang keras di industri cloud.

Fase 2: Mekanisme SSH Public/Private Keypair Authentication 08.30 - 09.30 (60 Menit)

Pembedahan kriptografi asimetris: Private Key (id_rsa / id_ed25519) disimpan rahasia di laptop admin dengan izin 600, sedangkan Public Key (id_rsa.pub) dipasang di server tujuan di file ~/.ssh/authorized_keys.

Fase 3: Bedah Konfigurasi Hardening & Proteksi Fail2ban 09.30 - 10.30 (60 Menit)

Membahas parameter sshd_config: Mengganti port default ke Port 2222, PasswordAuthentication no, dan konfigurasi jail /etc/fail2ban/jail.local (maxretry = 3, bantime = 1 jam) yang memblokir IP penyerang otomatis via IPTables.

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Persiapan terminal PowerShell / Git Bash di laptop client.

Fase 4: Job Sheet Praktikum Mandiri — Key Generation & Jail Test 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet Genap 3: (1) Generate RSA 4096-bit keypair (ssh-keygen -t rsa -b 4096), (2) Transfer public key dengan ssh-copy-id -p 2222 user@192.168.10.10, (3) Matikan login password, (4) Uji login instan tanpa password, (5) Install fail2ban dan simulasikan 3 kali salah password dari PC teman hingga IP-nya di-banned otomatis.

Fase 5: Skenario Troubleshooting: Permission 0644 vs 0600 & Host Key Verification 13.15 - 14.15 (60 Menit)

Siswa memperbaiki error "Permissions 0644 for 'id_rsa' are too open" (diperbaiki dengan chmod 600) dan menghapus entri lama di ~/.ssh/known_hosts akibat instalasi ulang server.

Pengerjaan evaluasi teori CBT 30 menit, checklist verifikasi SSH keypair oleh guru, dan pengantar materi RAID & Storage Server.

2 Konfigurasi Hardening SSH & Fail2ban

# 1. /etc/ssh/sshd_config — Parameter Hardening Standar CIS Benchmark 
Port 2222                             # Hindari scanning massal di port standar 22
PermitRootLogin no                    # Dilarang login langsung sebagai root!
PubkeyAuthentication yes
AuthorizedKeysFile .ssh/authorized_keys
PasswordAuthentication no             # Matikan autentikasi password (Wajib Keypair)
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 2
# 2. /etc/fail2ban/jail.local — Konfigurasi Penjara Otomatis IPTables 
[sshd]
enabled = true
port = 2222
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
findtime = 600
bantime = 3600                        # Blokir IP selama 1 Jam jika gagal login 3x
