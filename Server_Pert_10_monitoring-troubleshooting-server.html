Monitoring Kinerja & Troubleshooting Layanan Server

Menggunakan utilitas pemantauan real-time (htop, journalctl, Zabbix/Grafana), menganalisis log error layanan (systemctl), dan menyelesaikan skenario gangguan server secara sistematis.

1 Utilitas Monitoring Performa Linux CLI

# 1. Monitoring interaktif CPU, Memory & Process
htop

# 2. Cek penggunaan kapasitas penyimpanan (Disk Space)
df -h

# 3. Cek port yang sedang listening (aktif) dan prosesnya
sudo ss -tulpn

2 Analisis Log Error Layanan (systemctl & journalctl)

# 1. Memeriksa status dan pesan error layanan yang gagal start
sudo systemctl status apache2

# 2. Membaca log real-time layanan spesifik (Live stream)
sudo journalctl -u bind9 -f

# 3. Memeriksa riwayat percobaan login mencurigakan (Keamanan)
sudo tail -f /var/log/auth.log
