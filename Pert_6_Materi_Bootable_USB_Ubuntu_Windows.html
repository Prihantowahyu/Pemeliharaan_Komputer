Bikin Sendiri Media Instalasi:
Bootable USB Ubuntu & Windows

Sebelum sistem operasi bisa diinstal, komputer butuh "media" untuk membacanya. Modul ini merangkum dua SOP — membuat bootable Ubuntu dan Windows pakai Rufus — jadi satu alur yang sama-sama bisa kamu ikuti.

1tools: Rufus
2sistem operasi
4tahap besar
30–60menit proses burning
01 — Persiapan

Alat & Bahan

Tiga hal ini wajib siap sebelum membuka Rufus, baik untuk Ubuntu maupun Windows.

Bahan 1

Flashdisk kosong

Minimal 8 GB. Seluruh isinya akan terhapus total saat proses burning — pindahkan dulu data penting.

Bahan 2

Aplikasi Rufus

Gratis dan ringan. Gunakan versi Portable supaya langsung jalan tanpa instalasi.

Bahan 3

File ISO

File instalasi resmi. Untuk Ubuntu pilih versi LTS (paling stabil); untuk Windows gunakan ISO resmi dari Microsoft.

PENTING Gunakan flashdisk original. Flashdisk palsu/berkualitas rendah sering menghasilkan file korup dan bikin instalasi gagal di tengah jalan.
02 — Diagnosa

Kenali Dulu: MBR atau GPT?

Ini langkah yang paling sering diabaikan padahal paling menentukan. Skema partisi di Rufus harus sama dengan skema di komputer target — kalau beda, flashdisk tidak akan terbaca.

LEGACY BIOS

MBR — Master Boot Record

Dipakai PC/laptop generasi lama. Kalau motherboard kamu masih pakai Legacy BIOS, pilih skema ini.

UEFI

GPT — GUID Partition Table

Standar untuk PC/laptop modern. Sebagian besar laptop keluaran 5 tahun terakhir memakai skema ini.

Cara mengecek di Windows — jangan menebak, cek lewat Disk Management:

Ketik Disk Management di kolom pencarian Windows.
Klik kanan Disk 0 (drive utama tempat Windows terinstal) → Properties.
Masuk ke tab Volumes.
Lihat baris Partition style — catat hasilnya: GPT atau MBR.
03 — Eksekusi

Konfigurasi Rufus

Prosesnya mirip untuk kedua OS. Pilih tab sesuai sistem operasi yang mau kamu instal.

1

Pilih Device

Buka Rufus, pilih flashdisk kamu di menu Device. Pastikan namanya benar — salah pilih drive berarti data di drive lain ikut terhapus.

2

Boot selection

Klik SELECT, arahkan ke file .iso Ubuntu LTS yang sudah diunduh.

3

Partition scheme & Target system

Ubah dropdown ini sampai sama dengan hasil diagnosa kamu di langkah 02 (GPT atau MBR). Bagian lain biarkan default — Rufus sudah mengaturnya otomatis.

4

Klik START

Muncul pop-up peringatan data akan terhapus → konfirmasi. Proses injeksi ISO & boot sector berjalan 30–60 menit.

JANGAN Cabut flashdisk atau tutup Rufus selama proses berlangsung. Tunggu sampai status bar berubah hijau dan bertuliskan READY.
1

Pemilihan Device

Buka Rufus, fokus ke menu Device, pastikan flashdisk yang dipilih benar. Salah pilih drive = data di drive lain terhapus permanen.

2

Memuat file ISO

Biarkan pengaturan boot standar, klik SELECT, cari file ISO Windows yang sudah disiapkan.

3

Skema partisi

Pilih GPT untuk sistem modern (UEFI) atau MBR untuk sistem lama (Legacy) — cocokkan dengan hasil diagnosa. Bagian Image option biarkan default.

4

Burning & validasi

Klik START, konfirmasi peringatan format (OK). Tunggu indikator bar penuh dan berwarna hijau — flashdisk resmi jadi bootable installer.

INGAT Semua data di flashdisk akan terhapus. Backup dulu file penting sebelum mulai.
04 — Penerapan

Colok & Boot ke Flashdisk

Flashdisk sudah jadi bootable. Sekarang arahkan komputer target supaya membaca flashdisk, bukan hard drive seperti biasa.

Matikan komputer target secara total. Flashdisk tetap tertancap di port USB.
Tekan tombol Power, lalu langsung tekan berkali-kali tombol Boot Menu / BIOS sebelum logo sistem operasi muncul.
Layar hitam berisi daftar drive akan muncul. Pilih nama flashdisk kamu, tekan Enter.
Menu instalasi (GRUB untuk Ubuntu, Windows Setup untuk Windows) akan tampil. Ikuti proses instalasi dari sana.

Tombol Boot Menu tiap merek laptop berbeda-beda:

MerekTombol
Dell / AlienwareF12 atau F2
Lenovo / ThinkPadF12, F8, atau F1
HPF9 atau Esc
ASUSEsc atau F8
AcerF12 atau F2

Merek lain? Cari cepat di Google dengan kata kunci boot menu key [merek laptop kamu].

Alternatif lewat menu BIOS penuh (kalau tidak ada Boot Menu terpisah):

Masuk BIOS (biasanya tombol F2), buka menu Boot Priority.
Pindahkan flashdisk ke urutan paling atas (nomor 1).
Pastikan Boot Mode di BIOS cocok dengan skema partisi di Rufus — GPT sinkron dengan UEFI, MBR sinkron dengan Legacy.
Pilih Exit Saving Changes. Komputer restart dan langsung masuk ke instalasi.
Ringkasan

Poin Penting

Lakukan

  • Cek skema partisi (MBR/GPT) lewat Disk Management sebelum membuka Rufus.
  • Gunakan file ISO resmi dan flashdisk original.
  • Tunggu proses burning sampai status READY berwarna hijau.
  • Cocokkan Boot Mode di BIOS dengan skema partisi di Rufus.

Hindari

  • Jangan menebak skema partisi — salah pilih membuat flashdisk tidak terbaca.
  • Jangan cabut flashdisk atau tutup Rufus selagi proses berjalan.
  • Jangan lupa backup data flashdisk — semua isinya akan terhapus.
  • Jangan asal pilih Device di Rufus — drive yang salah bisa ikut terformat.
Tahap 1

Siapkan flashdisk, Rufus, dan file ISO.

Tahap 2

Diagnosa skema partisi lewat Disk Management.

Tahap 3

Atur Rufus, sinkronkan skema partisi, lalu burning.

Tahap 4

Boot dari flashdisk, mulai instalasi sistem operasi.
