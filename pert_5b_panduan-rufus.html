Bikin Flashdisk Bootable Windows pakai Rufus

8 langkah dari download ISO sampai flashdisk siap dipakai instal Windows di komputer lain.

⚠ Semua isi flashdisk akan terhapus habis saat proses ini. Pastikan tidak ada data penting di flashdisk sebelum mulai.
1
Siapkan Bahan

Download ISO Windows resmi dari situs Microsoft, dan Rufus dari rufus.ie (situs resminya). Secara teknis cukup 8GB, tapi lebih aman pakai flashdisk 64GB dari merek terpercaya (SanDisk, Kingston, dll) — flashdisk 32GB murah/tanpa merek sering gagal saat proses flashing ISO.

2
Colok Flashdisk & Buka Rufus

Rufus tidak perlu diinstal, langsung jalan. Di bagian Device, pastikan flashdisk kamu yang terpilih — cek ulang jangan sampai salah pilih harddisk internal.

Device
🔌 SanDisk Cruzer 16GB (E:) ▾
3
Pilih File ISO Windows

Di bagian Boot selection, klik SELECT lalu cari file ISO Windows yang sudah didownload.

Boot selection
Windows11_ID-ID.iso
SELECT
4
Atur Skema Partisi

Pilih sesuai jenis komputer tujuan instalasi (bukan komputer yang lagi kamu pakai sekarang).

◉ GPT
Untuk komputer ber-UEFI (kebanyakan laptop/PC 2015 ke atas)
UMUM DIPAKAI
○ MBR
Untuk komputer BIOS Legacy lama
5
Biarkan Pengaturan Lain Default

File system otomatis NTFS, volume label bebas diisi, sisanya biarkan bawaan Rufus.

File system
NTFS ✓
Volume label
WIN11 ✓
6
Klik START

Kalau muncul dialog tambahan (mis. skip TPM/Secure Boot untuk Windows 11), sesuaikan kebutuhan. Pilih Standard Windows Installation jika ditanya mode image (bukan Windows To Go).

▶ START
Standard Windows Installation
7
Tunggu Proses Selesai

Rufus memformat lalu menyalin file instalasi. Jangan cabut flashdisk sampai statusnya READY / 100%.

Menulis...
72%
8
Boot dari Flashdisk di Komputer Tujuan

Colok flashdisk ke komputer sasaran, nyalakan, lalu tekan tombol boot menu saat pertama nyala (beda-beda tiap merek). Pilih flashdisk dari daftar, instalasi Windows pun mulai.
