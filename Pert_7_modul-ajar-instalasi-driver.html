03 · Materi Inti — Bagian 1

Mengenal Driver & Device Manager

Sebelum praktik, siswa perlu memahami "mengapa" sebelum "bagaimana".

▲ APA ITU DRIVER?

Driver adalah perangkat lunak penerjemah yang menjembatani komunikasi antara sistem operasi dan komponen hardware. Tanpa driver, sistem operasi hanya mengenali hardware sebagai "perangkat asing" — mendeteksi keberadaannya, tetapi tidak tahu cara memanfaatkannya secara maksimal.

▲ AKIBAT JIKA DRIVER TIDAK TERPASANG

VGA tanpa driver membuat resolusi layar terbatas dan tidak bisa menjalankan aplikasi grafis berat. LAN/WiFi tanpa driver membuat komputer tidak dapat terkoneksi jaringan. Audio tanpa driver membuat speaker tidak mengeluarkan suara sama sekali.

Membaca Device Manager

Windows + X → Device Manager

Device Manager menampilkan status setiap perangkat keras dengan penanda visual berikut:

  • Segitiga kuning bertanda seru (!) — driver bermasalah, tidak sesuai, atau berjalan tidak optimal.
  • Tanda tanya abu-abu — perangkat sama sekali belum dikenali sistem (unknown device).
  • Panah ke bawah — perangkat terpasang tetapi dinonaktifkan (disabled).
  • Tanpa ikon tambahan — perangkat terdeteksi dan berfungsi normal.

04 · Materi Inti — Bagian 2

Empat Jenis Driver yang Wajib Dikuasai

Setiap jenis driver punya sumber resmi dan cara verifikasi tersendiri. Kenali dahulu vendor dan hardware ID sebelum mengunduh.

Driver VGA / Display

Grafis & tampilan layar

Mengatur output visual, resolusi, refresh rate, hingga akselerasi grafis untuk desain dan game.

  • Cek vendor via dxdiag atau tab Display Device Manager.
  • Unduh dari situs resmi: NVIDIA, AMD, atau Intel.
  • Pilih versi sesuai seri GPU dan arsitektur Windows (32/64-bit).
Sebelum ada driverResolusi rendah, tampilan pecah/buram
Sesudah driver terpasangResolusi native, tampilan tajam
Gambar 2 — Ilustrasi dampak driver VGA terhadap kualitas tampilan layar.

Driver Chipset

Motherboard & jalur data

Mengatur komunikasi antara prosesor, RAM, dan komponen motherboard lainnya agar sistem stabil.

  • Cek merek motherboard via System Information atau CPU-Z.
  • Unduh dari situs resmi Intel atau AMD sesuai chipset.
  • Instal di awal sebelum driver lain, karena menjadi fondasi komunikasi sistem.

Driver LAN / WiFi

Konektivitas jaringan

Menghubungkan komputer ke jaringan kabel maupun nirkabel agar dapat mengakses internet dan sumber daya lain.

  • Cek vendor via Network adapters pada Device Manager.
  • Umumnya Realtek, Intel, atau Qualcomm.
  • Jika belum ada internet, unduh dari komputer lain lalu pindahkan via flashdisk.

Driver Audio

Sistem suara

Mengaktifkan input dan output suara — speaker, headset, hingga mikrofon.

  • Cek vendor pada kategori Sound, video and game controllers.
  • Umumnya Realtek HD Audio pada mayoritas laptop dan motherboard.
  • Uji suara dengan file audio dan cek pengaturan playback device.

07 · Sebelum Praktik

Keselamatan & Kesehatan Kerja (K3)

Diingatkan singkat sebelum praktik dimulai, mengingat instalasi driver melibatkan restart sistem dan file yang diunduh dari internet.

▲ SEBELUM MENGUNDUH

Selalu unduh installer hanya dari situs resmi vendor. Hindari situs pihak ketiga yang menjanjikan driver "all-in-one" karena berisiko membawa malware.

▲ SELAMA PROSES INSTALASI

Jangan mematikan paksa komputer atau mencabut kabel daya saat instalasi/restart berlangsung — dapat menyebabkan driver korup atau sistem gagal boot.

09 · Studi Kasus

Skenario Troubleshooting

Latihan berpikir kreatif dan mandiri — dorong siswa mendiskusikan solusi sebelum membuka jawaban.

1 Setelah instal driver VGA, layar berubah blank atau bergaris
Masuk ke Safe Mode, buka Device Manager, lalu lakukan Roll Back Driver pada Display adapters. Setelah normal kembali, unduh ulang versi driver yang sesuai dengan seri GPU dan coba instal ulang secara bertahap.
2 Tidak ada koneksi internet untuk mengunduh driver LAN
Gunakan driver bawaan (CD/DVD driver motherboard) jika tersedia, atau catat Hardware ID perangkat dari tab Details di Device Manager, cari driver tersebut di komputer lain yang terkoneksi internet, lalu pindahkan file installer menggunakan flashdisk.
3 Installer menampilkan pesan "not compatible with this version of Windows"
Periksa kembali arsitektur sistem operasi (32-bit atau 64-bit) dan versi Windows yang digunakan melalui Settings → System → About, lalu unduh ulang driver dengan spesifikasi yang benar-benar sesuai.
4 Device Manager masih menampilkan tanda tanya setelah driver diinstal
Kemungkinan driver yang dipasang tidak cocok dengan perangkat. Salin Hardware ID lengkap dari tab Details, lalu cari driver yang benar-benar sesuai dengan ID tersebut di situs resmi vendor.

↺ Remedial

  • Pendampingan ulang instalasi 1 driver dengan bimbingan langkah demi langkah bersama guru.
  • Latihan tambahan membaca ikon status Device Manager pada beberapa contoh kasus.

↑ Pengayaan

  • Mencoba update driver ke versi terbaru menggunakan Device Manager langsung (Update driver).
  • Eksplorasi mandiri: mencari Hardware ID sebuah perangkat lalu menelusuri driver yang sesuai tanpa software bantuan otomatis.
