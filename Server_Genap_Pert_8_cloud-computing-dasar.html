1 Skenario & Alur Pembelajaran Tatap Muka (9 JP / 405 Menit)

Fase 1: Pendahuluan & Evolusi Datacenter Fisik ke Cloud 08.00 - 08.30 (30 Menit)

Apersepsi: Mengapa startup teknologi modern tidak lagi membeli server fisik bernilai ratusan juta rupiah? Guru memaparkan fleksibilitas Elasticity, On-Demand Self-Service, dan model biaya operasional (OpEx vs CapEx).

Fase 2: Taksonomi Layanan IaaS, PaaS, SaaS & Shared Responsibility 08.30 - 09.30 (60 Menit)

Membongkar batas tanggung jawab: Pada IaaS (AWS EC2, Google Compute Engine, DigitalOcean), penyedia cloud bertanggung jawab atas fisik hardware dan hypervisor, sedangkan pengguna bertanggung jawab mutlak atas patching OS, firewall, konfigurasi database, dan data aplikasi.

Fase 3: Otomasi Provisi Cloud Instance via cloud-init & Security Groups 09.30 - 10.30 (60 Menit)

Pembedahan skrip deklaratif #cloud-config: Otomatisasi pembuatan user, inject SSH public key, dan instalasi paket web server pada detik pertama saat VM booting tanpa intervensi manual.

Istirahat Lab / Coffee Break 10.30 - 10.45 (15 Menit)

Persiapan browser dan konsol cloud lab siswa.

Fase 4: Job Sheet Praktikum Mandiri — Deploy Instance VPS Cloud 10.45 - 13.15 (150 Menit)

Siswa mengerjakan Job Sheet Genap 8: (1) Membuat cloud instance Linux Server (1 vCPU, 1GB RAM) via konsol cloud/simulasi Proxmox Cloud-Init, (2) Menetapkan Security Group Ingress (hanya izinkan SSH Port 22 & HTTP Port 80), (3) Injeksi SSH Keypair, (4) Mengakses IP Publik Elastic Cloud via SSH terminal, (5) Memverifikasi website live di browser publik.

Fase 5: Skenario Troubleshooting: Security Group Port Blocked 13.15 - 14.15 (60 Menit)

Siswa menganalisis mengapa server cloud tidak bisa di-ping atau diakses via SSH (ternyata port belum diizinkan pada Virtual Firewall Ingress Provider Cloud, meskipun firewall internal OS sudah dimatikan).

Fase 6: Evaluasi CBT & Refleksi 9 JP 14.15 - 15.00 (45 Menit)

Pengerjaan evaluasi teori CBT 30 menit, checklist pengujian live VPS cloud oleh guru, dan pengantar Proyek Infrastruktur Terintegrasi (Capstone Project).

# Contoh Skrip Otomasi Provisi Cloud (#cloud-config / cloud-init) 
#cloud-config
users:
  - name: sysadmin
    groups: sudo
    shell: /bin/bash
    sudo: ['ALL=(ALL) NOPASSWD:ALL']
    ssh_authorized_keys:
      - ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI... admin@smk.lan

packages:
  - nginx
  - ufw

runcmd:
  - ufw allow 22/tcp
  - ufw allow 80/tcp
  - ufw --force enable
  - systemctl restart nginx
