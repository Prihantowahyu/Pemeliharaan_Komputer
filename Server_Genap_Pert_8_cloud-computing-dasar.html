1 Taksonomi Model Layanan Cloud: IaaS vs PaaS vs SaaS

Model LayananTanggung Jawab Pengguna (Siswa/Admin)Tanggung Jawab Cloud ProviderContoh Nyata
IaaS (Infrastructure as a Service)OS, Runtime, Middleware, Aplikasi, DataHardware fisik, Jaringan, Virtualisasi, DatacenterAWS EC2, Google Compute Engine, Linode/Akamai
PaaS (Platform as a Service)Aplikasi dan Data (Source code)OS, Runtime, Patching, Scaling, HardwareHeroku, Google App Engine, Vercel, Railway
SaaS (Software as a Service)Hanya menggunakan aplikasi dan pengaturan userSemua lapisan infrastruktur hingga kode programGoogle Workspace, Microsoft 365, Canva

2 Model Deployment Cloud & Provider Populer

Deployment ModelKarakteristikKelebihanKekurangan
Public CloudInfrastruktur dibagi bersama (multi-tenant) di server vendorBiaya fleksibel (pay-as-you-go), skalabilitas tak terbatasKontrol kepatuhan data terbatas
Private CloudInfrastruktur didedikasikan hanya untuk 1 organisasi (on-premise)Keamanan maksimal, kontrol hardware penuhInvestasi modal (CapEx) awal sangat tinggi
Hybrid CloudKombinasi Public Cloud + Private Cloud yang terhubung VPN/DirectConnectFleksibilitas: data rahasia di private, web publik di cloudKompleksitas konfigurasi dan integrasi jaringan
