Evolusi Container: Mengapa Docker Jauh Lebih Ringan daripada VM?
⏱ 08.30 – 09.30 · 60 Menit
▼
Virtual Machine (VM)
  • Setiap VM membawa Guest OS utuh (memakan RAM 1-2GB dan disk 10-20GB)
  • Booting butuh waktu 30-60 detik
  • Isolasi tingkat hardware via Hypervisor
Docker Container
  • Berbagi Host Kernel Linux bersama (Namespace & cgroups)
  • Hanya membungkus aplikasi + libraries (Ukuran image cuma ~50MB)
  • Start seketika dalam waktu < 1 detik!

version: '3.8'
services:
  web_sekolah:
    image: nginx:alpine
    ports:
      - "8080:80"
    volumes:
      - ./html:/usr/share/nginx/html
    restart: always

  database:
    image: mariadb:10.6
    environment:
      MYSQL_ROOT_PASSWORD: RahasiaSuper123
      MYSQL_DATABASE: db_cloud
